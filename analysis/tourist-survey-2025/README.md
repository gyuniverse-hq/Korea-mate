# 2025 외래관광객조사 분석 작업

연구 결과 설명은 [docs/research/tourist-survey-2025](../../docs/research/tourist-survey-2025/README.md)에서 확인합니다.

## 예정된 구조
- `scripts/`: 분석 및 그래프 생성 코드
- `outputs/`: 비식별 집계·실험 점수
- `requirements.txt`: 재현용 의존성 고정 목록

현재 이 브랜치는 **문서 등록용 초안**입니다. 기존 공유패키지의 스크립트와 엑셀, PNG를 아직 업로드하지 않았으므로 실행 가능하다고 표시하지 않습니다.

원자료와 개별 응답 데이터는 GitHub 저장소 바깥에서 관리합니다. 코드를 옮길 때 로컬 원자료 경로를 설정할 수 있도록 정리하고, 환경 의존성 및 재실행 결과를 확인해야 합니다.
