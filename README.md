# Korea Mate

외국인 방문객이 K-Culture에 대한 관심을 한국에서의 실제 경험으로 연결할 수 있도록 돕는 AI 서비스 프로젝트입니다.

> **프로젝트 초기 단계:** 기능 범위, 기술 구성, 사용자 타깃은 팀 검토와 데이터 분석에 따라 변경될 수 있습니다.

## 저장소 안내

- [문서 인덱스](docs/README.md): 기획, 리서치, 서비스 설계, 기술 의사결정
- 분석 재현 코드는 `analysis/`에서 관리합니다.
- 기능별로 짧은 브랜치를 생성하여 Pull Request(PR)로 검토합니다.

## 협업 원칙

1. `main`은 검토된 기준 자료를 유지합니다.
2. `docs/*`, `research/*`, `feat/*`, `fix/*` 등 작업별 브랜치를 사용합니다.
3. 분석 결과는 **데이터 출처 → 표본/분모 → 가중치/방법 → 결과 → 한계 → 제품 결정**을 함께 기록합니다.
4. 원자료, 응답자 단위 데이터, 개인 식별정보, 토큰, `.env`는 커밋하지 않습니다.
5. 오프라인 추천 성능을 실제 클릭·방문·예약 전환 효과로 설명하지 않습니다.

## 출처

2025년 외래관광객조사: [공식 원자료·코드북 안내](https://touraz.kr/statistics?bbsSeq=310809_1127&boardMode=V).
