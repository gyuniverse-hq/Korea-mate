# Korea Mate

외국인 방문객이 K-Culture에 대한 관심을 한국에서의 실제 경험으로 연결할 수 있도록 돕는 AI 서비스 프로젝트입니다.

> **프로젝트 초기 단계:** 기능 범위, 기술 구성, 사용자 타깃은 팀 검토와 데이터 분석에 따라 변경될 수 있습니다.

## 팀원 작업 시작하기

**브랜치 및 PR 기본 흐름: `작업 브랜치 → develop → main`**

- **[팀원 협업 가이드](CONTRIBUTING.md)**: 로컬 Git 명령어, PR 생성·리뷰·병합 절차
- [Git 브랜치 운영 상세](docs/collaboration/git-workflow.md): 작업 유형, 역할, 완료 기준
- [브랜치 보호 설정 및 현재 제약](docs/collaboration/branch-protection.md): 실제 적용 상태, 관리자 설정 방법

`main`은 안정/발표·배포 기준, `develop`은 팀 작업 통합 브랜치입니다. GitHub의 기본 브랜치는 `main`이므로 **작업 PR 생성 시 `base: develop`을 직접 확인**하세요.

## 저장소 안내

- [문서 인덱스](docs/README.md): 기획, 리서치, 서비스 설계, 기술 의사결정
- 분석 재현 코드는 `analysis/`에서 관리합니다.
- 기능별로 짧은 브랜치를 생성하여 Pull Request(PR)로 검토합니다.

## 데이터·보안 원칙

1. 분석 결과는 **데이터 출처 → 표본/분모 → 가중치/방법 → 결과 → 한계 → 제품 결정**을 함께 기록합니다.
2. 원자료, 응답자 단위 데이터, 개인 식별정보, 토큰, `.env`는 커밋하지 않습니다.
3. 오프라인 추천 성능을 실제 클릭·방문·예약 전환 효과로 설명하지 않습니다.
4. 실제 브랜치 보호 규칙은 아직 강제되지 않으므로 직접 push와 리뷰 누락을 팀 차원에서 관리해야 합니다.
