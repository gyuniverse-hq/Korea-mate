# ADR-001: 초기 개인화 추천 도입

- **상태:** 제안(Proposed) — 팀 검토 전
- **작성일:** 2026-10-15
- **관련 근거:** [2025 EDA v2](../research/tourist-survey-2025/eda-v2.md)

## 맥락
Korea Mate는 처음 이용하는 여행자에게 음식·쇼핑 외에도 관심이 있을 만한 K-Culture 체험을 보여주려 합니다. 전체 인기순 추천만으로는 세그먼트별 활동의 차이를 충분히 반영하기 어렵습니다.

## 관측된 근거
2025년 외래관광객조사 여가·친지방문 응답자(n=12,339) 기반 오프라인 분석 결과, 식도락·쇼핑을 제외한 탐색 체험 13개 대상으로 전체 인기순 NDCG@3=0.6640, 세그먼트 인기순=0.7058, LightGBM=0.7267이었습니다. 이는 **실제 앱 전환율 개선이 아니라 과거 활동 예측 정확도 개선**을 뜻합니다.

## 제안 (확정 아님)
- 초기에는 사용자가 선택한 관심사를 명시적으로 받되, 필수 입력을 최소화합니다.
- 국가/연령/방문경험 기반 기본 추천과 개인화 ML을 비교 실험합니다.
- 성별 제공은 선택적으로 처리하고, 미입력 상황 성능을 별도 평가합니다.
- 제품 내 클릭·저장·계획·방문 데이터를 수집한 뒤 추천 효과를 재검증합니다.
- 개인화 결과와 전체 인기 콘텐츠는 구분해 보여줍니다.

## 대안
1. 전체 인기순만 제공: 단순하고 관리가 쉽지만 세그먼트 차이를 반영하기 어렵습니다.
2. 세그먼트별 인기순: ML보다 단순하고 오프라인 성능 개선이 확인됩니다.
3. ML 개인화: 추가 성능은 있으나 재현성·운영·공정성 검증 비용이 발생합니다.

## 결정 전 확인
- 사용자 입력 부담 및 개인정보 최소화
- 추천할 실제 장소·행사 정보의 확보/갱신 가능성
- ML과 세그먼트 인기순의 온라인 사용자 과제 비교
- 트렌드·운영시간 등 최신성 필터 적용
