# KoreaMate 경쟁·시장·사업모델(BM) 분석 v0.1

작성 2026-10-18 · 외부 웹 공개 자료 조사 · **회사 공개 홍보, 언론 보도, 제3자 재무집계를 구분**

## 0. 비교 원칙

- '2025년 방한 외래관광객 약 1,893만 6,562명'은 국가 단위 방문 **건수**이며 KoreaMate의 유효 고객·유료 고객·매출 규모가 아니다. 개인별 중복방문, 여행 목적·언어·취향·접근성을 걸러야 TAM/SAM/SOM을 추정할 수 있다.
- 비교 서비스의 '모든 기능 미구현'이라고 추론하지 않는다. 아래 내용은 공개 서비스 설명에서 **확인된 기능/강점**이며, 없는 기능을 확인한 부재 증거는 아니다.
- 아래 금액의 법인·회계 범위, 연도, 통화가 다르다. **매출(revenue)과 총거래액(GTV/GMV), 제휴 주문 건수, 이용자 수를 더하거나 직접 순위화하지 않는다.**
- 이용자·전환·실적 수치가 사업자 주장일 때 실험적 효과로 재인용하지 않는다.

### 별도 전략 비교: MyRealTrip

- 2025년 매출 약 **1,120억 원**, 총거래액 약 **2.3조 원**(2025년 국내 법인 별도 재무 공개/언론 보도). 총거래액은 매출 아님.
- 주력 고객과 사업 범위가 한국 방문 외국인만은 아니므로, 한국 인바운드 서비스의 직접 시장 점유율 비교 대상은 아님.
- 2026-09-11 보도에 따르면 **Creatrip 지분 전량 인수 의결**, 주식교환·연내 자회사 편입 추진, 브랜드 독립 운영 계획. 2026-10-18 현재 인수 절차가 모두 종결되었다고 단정하지 않는다.
- 플랫폼 결합, 고부가 전문 체험과 예약·결제 연계, 공급 제휴망의 중요성을 검토하는 사업구조 참고 사례.

### 기능 차별화에서 즉시 수정해야 할 주장

- **'AI로 여행 일정을 추천한다'는 독점이 아니다.** TripGenie는 개인화 일정 생성, 예약 연결, 협업 일정과 여행 중 지원을 설명한다.
- **'한국 예약 장벽을 해결한다'는 독점이 아니다.** Trazy는 K-pop Concierge를 통해 이용 조건을 정한 예약 지원을 제공한다.
- **'외국인을 위해 현장 도움을 준다'는 독점이 아니다.** Creatrip Buddy가 예약 고객 대상 여행 지원을 제공한다.
- **'한국 문화/뷰티 상품을 발견하고 예약한다'는 독점이 아니다.** Creatrip, KKday, Klook 등이 이미 관련 체험 상품을 취급한다.
- 따라서 차별점은 **각 기능의 존재가 아닌 특정 고객 과제에서 정확도·성공률·시간·신뢰도가 실제로 나아지는가**로 정의한다. 경쟁사의 특정 기능이 없다는 주장은 직접 테스트 전까지 보류한다.

## 2. 시장에 대한 가설: 기존 파이와 새로운 파이

**기존 소비 대체(경쟁 확보):** 이미 예약/소비 의사가 있는 사용자가 기존 OTA·검색 대신 KoreaMate를 경유하도록 만든다. 주요 지표: 경쟁 과제 대비 선택률, 유효 예약 유입, 가격·운영 안내 정확도, 제휴사의 귀속 매출.

**미실현 경험 전환(시장 확대):** 사용자가 콘텐츠는 봤지만 예약·언어·시간·운영 제약 때문에 포기했을 가능성이 있는 활동을 *추가적인 실행*으로 연결한다. 주요 지표: 원래의 미실현 의도, 장애 원인, 실제 가능한 대안 선택, 확인된 방문·예약 및 사용자 보고. **단순한 '저장/클릭' 또는 '원래는 안 갔을 것'이라는 자기보고만으로 순증을 확정하지 않는다.**

**제안:** 두 가설을 모두 열어두고, 각각 다른 실험으로 검증한다. 제품의 더 큰 잠재력은 미실현 경험의 연결에 있다고 가정하지만 현재 확정된 성과는 없다.

### 단위경제성 예시(가정이지 예측이 아님)

- 월 **10,000건**의 유효 사용자 세션, 예약 파트너 클릭 **20%** → 2,000건
- 클릭 후 실제 예약 전환 **5%** → 100건
- 예약 객단가 **8만 원**, 인정 수수료율 **8%** → 월 총 수수료 640,000원
- 세션당 수수료 **64원**. 광고 유입비, 취소/환불, LLM·지도·번역·API 비용, 상담 인건비를 빼기 전.
- 실제 계약 수수료율·귀속 방식·예매 조건은 미확인. 위 수치는 **경제성의 민감도**를 보여주기 위한 입력값이므로 수익 전망에 사용하지 않는다.
- 이 가정만으로는 고비용 AI 상시 제공을 합리화하기 어려울 수 있다. 비용구조와 반복 사용·파트너 지불 모델을 함께 비교할 필요가 있다.

## 4. 실제 경쟁 비교를 위한 체크리스트

동일 사용자·동일 상황·동일 날짜·동일 과제로 Creatrip / Trazy / Klook / KKday / TripGenie / KoreaMate 시연을 기록한다.

- 콘텐츠에서 해당 실제 경험을 식별할 수 있는가?
- 유효기간·운영일·예약·외국인 본인확인 제약을 **출처와 함께** 확인하는가?
- 불가/불명확 상태를 불가·미확인으로 정확히 구분하는가?
- 사용자의 목적을 보존한 대안을 제시하고 동선 충돌을 해결하는가?
- 완료 전에 허위 가용성·예약 확정·가격을 주장하지 않는가?
- 해결 전후 소요시간·성공 여부를 비교할 수 있는가?
