## 다음 작업 후보

### A. 연구 산출물 신뢰도 보강 (선행하기 좋은 작업)

**질문:** 현재 분석을 다른 팀원이 재현·검토할 수 있는가?

- [ ] `requirements.txt` 기반 새 가상환경에서 모든 주요 스크립트 실행 후 CSV·JSON 값 비교
- [ ] 코드 내 하드코딩된 입력/출력 경로를 환경변수나 CLI로 정리하고 민감 파일 업로드 방지 확인
- [x] EDA v1·v2 대표 수치를 중간검토·v3과 원자료로 대조하고 핵심 12개 지표 일치 확인 (2026-10-16 EDA v4)
- [x] v2 전체 JSON 및 v3 통제분석 JSON 재실행 일치 확인 (현재 환경)
- [ ] 복합표본 분산 및 작은 하위집단 표본의 해석 한계 검토
- [ ] 원자료·코드북 이용 조건과 익명 집계 재배포 범위 확인

**완료 기준:** 동료가 공식 원자료를 별도 준비했을 때 문서대로 실행해 주요 수치를 재현하고, 차이 발생 시 원인을 기록할 수 있다.

### B. 후속 EDA (새 분석 질문 중심)

**질문:** 국가·방문경험 차이가 콘텐츠 발견 경로와 체험 분야별로 어떻게 달라지는가?

- [ ] **HOW 확장:** 국적 × 연령 × 방문횟수별 SNS·영상·여행앱 정보 접촉 차이의 가중 분석
- [ ] **세그먼트 안정성:** 첫 방문·재방문 × 국가별 주요 활동의 표본 수·효과 크기·불확실성 비교
- [ ] **활동 조합:** K-pop 장소 → 공연, 전통문화 → 전시 등 연관 패턴이 국가·시점별로 반복되는지 점검
- [ ] **추천 모델 추가 검증:** 성별 제외·관심사 직접 입력·인기순/세그먼트/단순 ML 비교. 직접 선택 관심사는 원조사에서 동일하게 측정되지 않아 별도 사용자 데이터가 필요함
- [x] **WHEN & WHERE 설문 기반 1차 분석:** 2025 조사 월×지역, 국적×지역, 지역 간 동반 방문. 실제 행사·장소 정보 또는 실시간 트렌드를 증명하지 않는다는 제약 명시
- [x] **Korea Pulse 외부 데이터 명세·정규화 규칙 확인:** EDA v5에서 공통 필드/좌표·기간·링크 오류를 처리하는 합성 테스트 11건 통과
- [ ] **외부 API 실데이터 검증:** 서울시·TourAPI 실제 응답 ≥100건(가능 범위), 필드 결측·갱신·종료/취소·지역코드·공공누리 적용 및 품질 측정 (키와 네트워크 필요)
- [ ] **다년 반복 검증:** 2023~2026 공식 비교 가능한 조사 문항을 확보하고 계절/지역 차이의 재현 여부 확인

**완료 기준:** 새로운 분석이 제품 가설의 우선순위를 바꿀 만한 결과를 제시하거나, 근거 부족을 정직하게 기록한다.

### C. 핵심 문제 가설의 직접 사용자 검증

**질문:** SNS/콘텐츠에서 발견한 관심을 실제 방문 준비로 옮길 때 어디서 막히는가?

검증할 과제 후보:
1. SNS 촬영지 스크린샷 → 정확한 장소·운영일·이동방법 확인 → 여행 계획에 추가
2. 미용서비스 관심 → 가격·예약 가능 여부·이용 언어 확인 → 방문 준비
3. 첫 방문 기본 안내 → 교통/매장/현장 규칙 이해 → 일정 작성

기존 검색 방법과 후보 서비스의 시험용 흐름을 동일 과제로 비교. 정보 오류·지난 행사 추천도 별도 기록한다.

- 기록: 성공 여부, 소요 시간, 탐색 단계, 사용 서비스 수, 잘못된 정보, 포기 이유, 주관 난이도
- 모집 예시: 언어권/방문경험이 다른 5~8명 **탐색용** (통계적 개선율 추정 불가)
- 결과가 나오기 전까지 시간 80% 단축, 방문 전환 향상 같은 효과 숫자는 발표에 사용하지 않음

**완료 기준:** 최소 한 개 이상 반복되는 이용자 불편 또는 문제 가설 반례를 관찰해 정리한다.

### D. 기능 및 주제 검토는 별도로 결정

A~C의 자료를 바탕으로 기능 후보를 `확인된 문제 / 간접 근거 / 테스트 필요 / 증거 없음`으로 분류합니다. 주제 미확정이므로 기능을 특정 방향으로 강제하거나 개발 백로그를 확정하지 않습니다.
