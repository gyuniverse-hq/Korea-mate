# Korea Mate · EDA 5차: 외부 관광·행사 데이터 연계 가능성 검증

**기준일:** 2026-10-16  
**상태:** 최종 프로젝트 후보 검증 자료 / 주제·기능 미확정  
**상세 구분:** 공식 데이터 명세 검증 **완료** · 응답 정규화/검사 코드 및 테스트 **완료** · 실제 오픈API 행별 품질 측정 **미완료**

## 0. 핵심 판단

1. **Near You는 구현 가능한 후보:** 한국관광공사 국문 관광정보서비스의 `locationBasedList2`, `areaBasedList2`, `detailCommon2`가 공식적으로 개방돼 있으며 위치 기반 관광 콘텐츠에 활용 가능하다. 서울시 문화행사도 위도/경도와 행사 상세주소를 제공하는 명세다. **정확한 필드 충족률·실제 응답·거리 정확도는 인증 후 확인해야 한다.**
2. **Korea Pulse는 부분적으로 가능:** 행사 시작·종료일과 장소가 있으면 행사 후보, 종료 임박 후보를 제시할 수 있다. **행사 기간 내에 있다는 사실은 실제 운영 중·예약 가능·매진 아님을 보장하지 않는다.** 또한 이러한 행사를 '요즘 인기 있는 팝업'이라고 자동 판정할 근거는 없다.
3. **외래관광객조사 EDA와 직접 결합할 수준은 아직 아님:** 외래관광객조사 `Q9_2`는 방문 지역(17개 광역 시도), `D_MON`은 조사 월이고, 행사 API는 장소별 상세 정보다. 코드체계·시간 단위를 표준화해도 어떤 관광객이 어떤 행사에 참여했는지 확인되지 않는다.
4. **실제 API 품질은 측정하지 못함:** 서울 OpenAPI의 공개 `sample`키 요청은 이 실행환경에서 DNS/네트워크 접근 오류로 실패했다. TourAPI는 이 실행환경에서 서비스 인증키가 없어 호출하지 않았다. 따라서 행별 결측률, 정확도, 중복률, 최신성의 실측값은 아직 없다.

### 호출 및 사용 조건 확인

- 서울시 문화행사 API는 공식 페이지에 **일 1회 갱신**으로 표시되며, 공개 안내 예시는 `http://openapi.seoul.go.kr:8088/(KEY)/json/culturalEventInfo/1/5/` 구조다. 공식 명세에서 `LOT=경도(X)`, `LAT=위도(Y)`이다.
- 한국관광공사 국문 GW는 JSON/XML REST, 무료 서비스로 소개되며 개발계정은 **1,000건**의 신청 가능 트래픽이 안내된다. 개발단계는 자동 승인, 운영단계는 심의 대상이다. 기본 정보의 '실시간' 갱신 표기를 개별 항목의 즉시 운영 확인으로 간주하지 않는다.
- 한국관광공사 관광 이미지의 별도 공공누리 이용 조건은 이미지별 확인이 필요하다. API 이용이 가능하다는 사실로 모든 사진의 재배포 권한이 보장되지는 않는다.
- 서울 문화행사 자료의 공공누리 출처표시 조건을 준수하고 원본 상세 페이지로 연결하는 구성이 적합하다.

## 3. 정규화 규칙 및 위험 방지

동봉한 `event_contract.py`는 공급자별 필드를 다음의 최소 공통 구조로 전환한다.

| 공통 필드 | 서울 문화행사 | TourAPI 행사 | 처리 원칙 |
|---|---|---|---|
| `title` | `TITLE` | `title` | 필수 콘텐츠 텍스트 |
| `start_date`, `end_date` | `STRTDATE`, `END_DATE` | `eventstartdate`, `eventenddate` | 기간 판별(상세 공연 회차별 운영시간 아님) |
| `longitude`, `latitude` | `LOT`=lon, `LAT`=lat | `mapx`=lon, `mapy`=lat (실제 응답은 추후 검증) | 숫자·범위 검증, 뒤바뀜 의심 시 지도 노출 보류 |
| `source_url` | `HMPG_ADDR`(없으면 `ORG_LINK`) | 콘텐츠 ID를 임의 URL로 변환하지 않음 | 검증된 실제 URL만 사용 |
| `source_record_date` | `RGSTDATE`(등록일) | `modifiedtime` 후보 | 수집시각과 구분. 등록일을 최신 수정일로 오해하지 않음 |
| `fetched_at_utc` | 요청 수집 시각 | 요청 수집 시각 | API를 가져온 시각. 장소 방문 확인 시각이 아님 |

- 행사 상태는 `future / within_date_window_only / expired / invalid / unknown`으로 구분한다. `within_date_window_only`는 '운영 중'이라는 사용자-facing 표현을 허용하지 않는다.
- `ending_soon_candidate`는 **현재가 표기 행사 기간 내이며 7일 이내 종료 예정**인 경우에만 참이다. **예약 가능/입장 가능 정보가 아니다.**
- 좌표 범위는 광역 한국 영역을 이용해 1차 검증한다. 행정구역·정확한 장소 확인에는 주소/지도 API 등 별도 검증이 필요하다.
- `bookable`, `operating_now`는 항상 **미확인(`null`)**으로 두며, 예약 시스템·당일 공지·현장 운영 정보를 추가 확인해야 한다.
- `LOT`과 `LAT` 의미를 뒤집은 비공식 예제가 있을 수 있으므로 반드시 서울 공식 필드 정의를 따른다.
- 행사 상세 링크가 없는 항목은 사용자가 행동으로 이어질 수 없으므로 추가 확인이 필요하다.

## 5. 검증 코드 및 테스트 결과

- 스크립트: `event_contract.py` (정규화/품질 집계), `probe_open_apis.py` (선택적 라이브 조회), `test_event_contract.py` (표준 라이브러리 테스트).
- 테스트 픽스처: `fixtures/*_synthetic.json`. **임의 생성 테스트 데이터이며 실제 API 응답이 아님.**
- 2026-10-16 기준 단위 테스트 **11/11 PASS**.
- 합성 테스트 데이터의 품질 통계는 성능 검증용 수치가 아니므로 실제 행사 품질 지표로 사용 금지.
- 서울 API 공식 가이드는 HTTP(8088)를 사용하므로, 비공개 발급키를 평문 HTTP로 보내지 않도록 샘플키 이외 전송을 차단했다. 제품에서는 TLS를 제공하는 인증된 게이트웨이/중계가 확보되어야 한다.
- 실제 API 조회는 환경변수 `SEOUL_OPEN_API_KEY`, `TOURAPI_SERVICE_KEY`를 사용하며 소스 코드/보고서/로그에 값을 저장하지 않는다.

**실행:**
```bash
cd analysis/tourist-survey-2025/external-data
python -m unittest -v
python probe_open_apis.py --date 2026-10-16
# 공인 네트워크에서 서울 공개 sample만 시험할 경우:
SEOUL_OPEN_API_KEY=sample python probe_open_apis.py --live --allow-http-seoul --date 2026-10-16
# 공공데이터포털 TourAPI 키가 발급된 경우:
TOURAPI_SERVICE_KEY="$MY_TOURAPI_KEY" python probe_open_apis.py --live --date 2026-10-16
```

## 6. 다음 단계의 명확한 완료 기준

**Gate A — API 실제 호출 (필수)**
- 서울 문화행사 100건 이상(또는 실제 제공 가능한 최대 수), TourAPI 행사·지역 POI 각각 100건 이상 표본을 확보할 수 있는지 확인.
- HTTP 성공/응답 코드/요청 지연/누락 필드/중복 데이터/기간·좌표 오류를 기록. 발급키나 행별 개인정보는 저장하지 않음.
- 날짜 및 운영시간, 공공누리 콘텐츠 제한, 페이지별 갱신주기를 확인.

**Gate B — 데이터 정합성 (필수)**
- 같은 행사의 날짜·장소·좌표를 공식 상세 페이지와 표본 수십 건 대조.
- 서울 자치구·TourAPI 지역코드·EDA 17개 시도의 대응 테이블을 생성. 관광객의 Q8 활동을 행사 장소와 임의로 결합하지 않음.
- 종료/취소/변경/삭제 신호를 최소 2회 이상의 수집 차이로 확인하되, 목록에서 빠졌다는 사실만으로 취소 처리하지 않음.

**Gate C — 서비스 가설 (이후)**
- Korea Pulse는 뉴스·SNS 관심도·행사 검색량 데이터가 추가로 확보되어야 **트렌드 순위**를 검증할 수 있음.
- Near You는 실제 좌표 유효률/중복률과 원본 링크 정확성을 확인해야 지도·추천 서비스 MVP로 확정 가능.
- 주제 선정 전까지 이번 검증을 **데이터 확보 가능성 평가**로 유지.

## 7. 판단

**권고:** Near You는 공식 POI/행사 API에 기대어 시제품 검토를 계속할 수 있다. Korea Pulse 중 **행사 예정/종료 임박 안내**는 구현 후보이지만, **바이럴/인기도/실시간 예약 가능성**은 다른 데이터 수집·검증 없이는 주장하지 않는다.

**최종 판정:** 연결 가능한 공식 API는 확인됨. **API 운영 품질/실시간성/데이터 충족률은 미검증**. 사용자에게 보이는 문구는 실제 근거 수준에 맞추어 제한해야 한다.
