## 해석 경계

1. `lDongRegnCd`가 목록에 전부 존재하나 이번 `ldongCode2` 매핑 로직이 지역명을 만들지 못했습니다. **API가 잘못되었다거나 지역코드가 무효라고 판정하면 안 됩니다.** 공식 응답 필드명을 안전하게 확인하고 규칙을 수정해야 합니다.
2. 상세 API 12건의 필드 존재는 검증했지만 **행사 원본 운영 여부·취소·예약가능 여부를 주최 측에서 확인한 것은 아닙니다.**
3. 서울 `sample`은 공급자가 선정한 5건입니다. 한 건 일치했다고 양 API 전체 중복률을 20%라고 계산하면 안 됩니다. 서울 API 전체 데이터의 정식 인증 조회가 필요합니다.
4. 상세 좌표가 12건 모두 비교 가능하다고 해서 모두 동일 좌표라는 뜻은 아닙니다. 비교 오차 임계치를 별도로 점검하고, 독립 지리 기준과 확인해야 합니다.
5. 코드가 기록·저장하는 값은 집계 수치이며 원본 event ID, 제목, 주소, 좌표, 인증키를 GitHub에 남기지 않습니다.

## 제품 설계에 주는 의미

- **Near You:** 공통/상세 조회의 좌표와 주소가 충분히 제공되므로 지도 후보 생성에 활용 가능. 독립 위치 정합성 확인 필요.
- **Korea Pulse:** 공개 행사 기간과 행사장·요금·상세 링크 정보 제공 가능. **인기·예약가능·현장 운영 확정**은 아직 불가.
- **지역 매핑:** `lDongRegnCd`를 기준으로 공식 코드표를 맞춘 뒤 주소와 교차 대조하는 것이 다음 과제.
- **서울 결합:** 샘플 5건에서 하나의 후보 중복은 관측됐지만 전체 중복·추가 콘텐츠 규모는 아직 확인하지 못함.
