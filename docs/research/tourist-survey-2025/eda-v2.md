**분석일:** 2026-10-15  |  **데이터:** 2025년 외래관광객조사 사용자 제공 원자료·코드북  |  **버전:** v2.0

> **이번 단계의 핵심 질문:** 실제 관광활동에는 추천 가능한 연관 패턴이 있는가? 행동 기반 여행자 유형은 발견되는가? 그리고 사전 정보 기반 개인화가 인기순 추천을 개선하는가?

## 1. 경영·기획 요약
- **전체 응답:** 16,110명. 추천 서비스와 직접 관련 있는 여가·친지 방문 집단 **12,339명**을 분석 분모로 채택. 조사 가중치 적용, 간이 유효표본크기 약 **8,501**.
- **행동 연관:** K-pop·촬영지 참여와 공연 관람은 Lift **2.96**, 전통문화체험과 박물관·전시는 **2.43**, 고궁·역사와 전통문화체험은 **2.15**. K-pop과 뷰티·미용서비스는 **0.81**로 오히려 함께 발생하는 정도가 독립 가정보다 낮았다.
- **탐색적 군집:** 가중 K-Means로 **7개** 행동 패턴을 추출. 실루엣 0.209로 뚜렷한 자연 군집이라고 단정하기 어려워 **UI 설계에 참고하는 임시 분류**로만 제안한다.
- **추천 품질 (전체 15개 체험):** NDCG@3 인기순 0.8415 → LightGBM 0.8561 (**+1.46%p, 상대 +1.7%**).
- **추천 품질 (식도락·쇼핑을 제외한 13개 탐색 체험):** NDCG@3 인기순 0.6640 → LightGBM 0.7267 (**+6.26%p, 상대 +9.4%**).
- **온보딩 간소화:** 국적·연령·성별·방문횟수만 사용한 LightGBM은 탐색 NDCG@3 **0.7184**로 6개 특성 모델 **0.7267**와 차이가 제한적이었다. 성별 제공은 선택적이어야 하며 성별 미제공 시 성능은 별도 실험 필요.

## 2. 분석의 재현성과 표본 기준
- **원본 변수:** `Q1` 관광 목적, `Q8a01..16` 관광활동 다중 응답, `weight` 가중치, `D_NAT` 국적, `D_AGE` 연령, `D_SEX` 성별, `D_NUM` 방문횟수, `TYP` 여행형태, `D_MON` 조사 월. `pnid`는 중복검증에만 사용.
- **분석 모집단:** `Q1 in {1, 2}`(여가·위락·휴식 또는 친지 방문). 의료·건강검진 `Q8a14`는 일반 체험 추천 대상에서 제외. 실제 여행활동(Q8)은 **연관·군집에는 사용하지만 ML 입력에는 사용하지 않음**.
- **가중 비율:** `Σ(weight×참여) / Σ(weight×분모)`. 빈 활동 칸은 미참여(0)로 코딩. 거부·결측 등 원자료 구조에 대한 원조사 가이드 확인이 필요함.
- **데이터 분할:** 1~8월 학습 **8,194명**, 9~10월 검증 **2,094명**, 11~12월 테스트 **2,051명**. 검증 기간에 설정을 선택하고 학습+검증으로 다시 학습한 후, 테스트는 마지막에 단 한 번 평가하는 설계.
- **모델 입력:** 최소 4개 (`D_NAT`, `D_AGE`, `D_SEX`, `D_NUM`), 확장 6개(4개+`Q1`, `TYP`). 향후 가입 시 알고 있는 사전 입력으로 간주한 변수만 사용. 실제 이용 상황의 수집 가능성은 별도 확인 필요.

## 3. 활동 간 연관규칙 (Association Rules)
Lift = P(B|A) / P(B). 1보다 크면 B가 A 참여자에서 더 자주 관측됨. **인과관계나 행동 전환의 증거는 아님.** 아래 수치는 조사 가중치를 적용했으며, 방향별 조건부 참여율은 달라질 수 있음.

| A → B | 가중 동반참여율 | P(B\|A) | B의 전체 참여율 | Lift | 응답 동반 n |
|---|---:|---:|---:|---:|---:|
| K-pop·촬영지 → 공연 | 2.23% | 14.03% | 4.75% | 2.96 | 283 |
| 전통문화체험 → 박물관·전시 | 9.75% | 56.65% | 23.28% | 2.43 | 1660 |
| 고궁·역사 → 전통문화체험 | 14.23% | 36.91% | 17.20% | 2.15 | 2405 |
| 뷰티·미용서비스 → K-pop·촬영지 | 1.81% | 12.92% | 15.87% | 0.81 | 220 |
| 뷰티·미용서비스 → 쇼핑 | 12.72% | 90.54% | 86.45% | 1.05 | 1669 |
| 자연경관 → 고궁·역사 | 29.65% | 51.01% | 38.57% | 1.32 | 4637 |

**해석:** ‘비슷한 사용자는 공연도 경험했습니다’는 K-pop 관련 장소 이용자에게 비교적 의미 있는 탐색 문구가 될 수 있다. 반대로 K-pop 관심이면 뷰티도 좋아한다고 일괄 가정하지 않는다. 패션·팝업은 조사 Q8과 정확히 맞물리는 개별 활동 문항이 없어 직접 연관성 검증 대상에서 제외.

## 4. 여행자 행동 기반 군집화 (Clustering)

| 5 | 0.1500 | 12.2% |

## 5. Cold-start 개인화 모델 검증
**목표:** 신규 가입 시 알 수 있는 정보만으로 실제 참여 활동을 다중 라벨로 예측하고 상위 3개 활동의 순위 품질을 검증.

| 모델 | 전체 활동 NDCG@3 | 탐색 체험 NDCG@3 | 인기순 대비 탐색 +%p |
|---|---:|---:|---:|
| 전체 인기순 | 0.8415 | 0.6640 | +0.00 |
| 세그먼트 인기순 | 0.8487 | 0.7058 | +4.18 |
| 로지스틱 회귀 | 0.8495 | 0.7233 | +5.93 |
| LightGBM 최소입력 | 0.8516 | 0.7184 | +5.44 |
| LightGBM | 0.8561 | 0.7267 | +6.26 |

전체 활동은 Food·Shopping이 매우 빈번하므로 점수가 이미 높다. **탐색 체험 점수는 Food·Shopping을 빼고 다시 상위 3개를 추천**한 결과이고, 해당 13개 활동 중 실제 참여가 한 개 이상 있는 테스트 대상(1,914명 / 가중 대상의 90.48%)을 평가 분모로 사용했다. 의료활동은 추천 정답에서 제외.

## 6. Korea Mate 기능 기획에 연결
| 제품 요소 | 이번 EDA로 확인한 것 | 지금 제안하는 방식 | 아직 검증 안 된 것 |
|---|---|---|---|
| **For You** | Cold-start 예측이 인기순보다 높은 오프라인 점수 | 초기 4개 속성 + 관심 선택권 제공, 단기 데이터 수집 후 ML/세그먼트 추천 비교 | 클릭·저장·방문 실제 전환 |
| **Travelers Like You** | 여러 활동의 동반 경험과 유형별 차이가 존재 | 세그먼트 인기 활동 / 함께 경험한 활동을 명확히 구분해 표시 | 온라인 행동 기반 유사 사용자 추천 |
| **Korea 101** | 첫 방문 그룹의 활동 차이는 1차 EDA에서 확인 | 첫 방문/재방문 안내 분기를 유지 | 선호의 원인, 맞춤 안내로 개선되는 이용 편의 |
| **Korea Pulse** | 추세·지역의 실시간성은 이 설문으로 알 수 없음 | 이벤트·트렌드 별도 데이터 확보 후 구현 | 로컬 유행 예측, 최신성, 실시간 유효성 |
| **See it → Live it** | 관심활동과 체험 간격은 관측, 사용자 이동 경로는 없음 | 태스크 실험을 별도로 설계 | 검색→예약 과정의 실제 시간·실패율 |
| **Beauty** | 미용서비스와 화장품 구매는 다른 행동(1차 EDA) | 쇼핑/화장품 콘텐츠와 미용 서비스 예약을 구분 | 예약 마찰이 중요 원인인지 |

**제안 UX 방향:** 전체 인기 콘텐츠와 **개인화 탐색 콘텐츠를 별도 행으로 보여주기**. 예를 들어 `Popular in Korea`는 범용 여행활동을, `For You`는 4개 기본 속성·사용자 선택 관심사로 가중한 체험 추천을, `People also experienced`는 연관분석 결과를 표시. 사용자 행동 로그가 쌓이면 신규 입력보다 행동 기반 신호를 점진적으로 강화한다.

## 7. 정확하게 발표하려면
✅ **할 수 있는 표현**: "2025년 외래관광객조사 12,339명을 대상으로 조사 가중치를 반영하고, 시점 분리 평가를 시행한 결과, 개인화 추천이 전체 인기순 추천보다 체험활동 NDCG@3에서 0.6640→0.7267로 개선되었습니다."

❌ **피해야 할 표현**: "Korea Mate를 쓰면 관광객의 실제 방문 확률이 9.4% 늘어납니다." 사용자 실험이나 로그 기반 전환율을 측정하지 않았기 때문.

❌ **피해야 할 표현**: "7가지 페르소나가 통계적으로 증명되었습니다." 군집 실루엣이 높지 않고 사용자 사전 입력만으로 군집을 바로 판단할 수도 없다.

## 8. 다음 실험 제안
1. **최소 입력 조합 검증:** 성별 미입력, 방문횟수 미입력 등 실제 회원가입 제약을 가정해 성능 민감도 재검증. 민감·불필요한 정보 입력을 강제하지 않는다.
2. **동일한 가입 경험 비교:** 인기순 → 세그먼트 → ML 추천을 블라인드 사용자 과제에서 비교하고, 저장·방문 의도/이유도 함께 수집.
3. **활동·콘텐츠 연결:** 활동 수준(Food, K-pop) 모델을 장소·행사 단위 데이터베이스와 연결하고 운영일/유효기간 필터 적용.
4. **새로운 신호 추가:** 관심사 2~3개 온보딩 체크와 앱 내 저장/좋아요/패스 로그로 실제 사용자 행동 기반 모델을 평가.
5. **군집 안정성:** 월별 재학습, 다른 거리함수, 누적 행동 기준으로 군집이 유지되는지 점검하고 필요하면 군집 없는 다중 선호 모델로 전환.

## 9. 분석상 제약
- **사후 응답 편향:** 2025년 실제 여행자 중 이미 한국 여행을 완료한 이들의 자기보고 활동을 대상으로 한다. 가입 시점의 진짜 관심과 다르고, 모델은 참여활동의 예측이지 미래 클릭/예약 예측이 아니다.
- **비교 가능성:** 2025년 월별 조사 기준 시간 분리 테스트 결과이며, 2026년 이후 계절·국적 구성이 달라질 경우 성능도 달라질 수 있다.
- **표본설계:** 조사 가중치는 적용했지만 복합표본 분산/층화 방식의 공식 신뢰구간은 계산하지 않았다. 부트스트랩은 보조 자료.
- **정보 접근성:** 성별/연령은 가입 시 사용자가 제공하지 않을 수 있으므로 선택적 정보와 설문 답변을 통한 대체 기능이 필요하다.
- **군집:** Silhouette 0.209는 명확히 떨어진 집단보다 연속된 선호 공간에 가까울 수 있다는 신호다.
- **활동 정의:** Beauty 서비스(`Q8a13`)와 화장품 쇼핑(`Q10_2`)을 혼동하지 않고, Popup/패션을 조사에 없는 항목으로 만들어내지 않았다.
- **변수 추적:** 학습 입력에 만족도·쇼핑 구매 품목·실제 참여활동·지출을 사용하지 않아 예측 시점 데이터 누수(leakage)를 피했다.
