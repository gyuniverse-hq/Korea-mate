# KoreaMate K-Culture 경험 비교 연구

이 폴더는 외국인의 **사전 관심→실제 경험**과 한국인의 **국내여행 활동**을 연결해 후보 경험을 발굴하는 *근거 검증 자료*입니다. 사용자 추천 효과, 한국인의 외국인 추천 의향, 최신 트렌드는 아직 검증되지 않았습니다.

- [연구보고서](2025-culture-experience-v0.1.md)
- [공통 문화 분류와 비교지표](comparison_crosswalk_v0_1.csv)
- [잠재 방한여행객 세부 문화 53개](potential_activity_detail_v0_1.csv)
- [경험 후보 30개](experience_candidates_v0_1.csv)

개별 응답자 원자료, 개인정보, 재배포가 제한될 수 있는 공식 보고서 원본 파일은 커밋하지 않습니다.
