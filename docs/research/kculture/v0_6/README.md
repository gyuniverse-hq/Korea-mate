## 실험
A: 관광지 카드/지도만 제공
B: 문화 맥락·관심사 설명까지 제공
C: A+B 및 실제 여행시점 시간·비용·교통·운영정보(출처 검증 필요) 제안
통제조건으로 GPT+지도+현행 예약앱. 평가: 관심 변화, 신규 경험 발견, 계획·실행 완료율, 시간/비용 예측 오류, 앱 전환, 재설명, 오안내율. 현재 실험 전.

## 자료 수집 가능성과 미완료
한국관광공사 지역별 방문자수 GW API는 광역·기초지자체 이동통신 기반 내외국인 자료를 제공함. **API 인증·실측값 적재는 아직 진행하지 않음**. 또한 관광지점 확정치 전체 파일도 아직 미수집. 이동통신 방문자는 순수 관광객과 같지 않다.
- https://www.data.go.kr/data/15101972/openapi.do
- https://know.tour.go.kr/stat/tourReportBizDis.do

## 방법·해석
관광객 조사 실방문, 잠재 방문의향, 5점 인지, 선정목록, 입장집계, 이동통신 방문자는 별도 데이터 레이어로 저장. 다른 분모를 차감해 잠재전환율이나 '외국인이 모르는 명소 점수'를 계산하지 않음. 2025 행정구역 기준 17개 시도 유지. 연구용 분류는 공식 기관 분류와 다름. 개별 관광지 최신 가격·이동시간·예약·영업은 검증 전.
