# KoreaMate 한국인·외국인 로컬 경험 교차 연구 v0.3

검토일: 2026-10-19. 기존 v0.1·v0.2 증분. **공식 자료와 미검증 가설을 구분하고 실제 제품 기능·우선순위·BM은 확정하지 않음.**

## 핵심 결과
- **한국인이 즐기지만 외국인은 거의 모른다고 검증된 경험: 0개.** 동일 장소·기간·인지 질문 또는 적절히 보정된 노출 데이터를 확보하기 전까지 그렇게 부르지 않음.
- **2025 제주 공식 조사**에서 내국인/외국인 공통 세부 만족도 **9항목** 확인. 내국인 vs 외국인: 관광지 매력 4.4/4.3, 음식4.3/4.1, 쇼핑4.1/4.2, 관광정보4.0/4.1, 제주 대중교통3.6/3.9, 교통정보3.8/3.9, 교통수단4.3/4.2, 방문지 편의성4.2/4.2, 숙박4.3/4.3. 가중 5점 척도, 통계적 차이 검정 전이며 **장소 인지도와 전혀 다른 지표**. [내국 자료](https://data.ijto.or.kr/prog/dataPick/bigdata/sub02/view.do?regSn=86) / [외국 자료](https://data.ijto.or.kr/prog/dataPick/bigdata/sub02/view.do?regSn=87)
- **부산 장소별 국내·해외 방문 집계**: 비거주 내국인 2025말~2026초 과거 방문 경험자 **944명**, 2024 외국 관광객 **1,060명**. 공통 5곳에서 광안리 내국54.1%/외국58.5%, 해운대50.6/40.8, 국제시장36.7/46.9, 감천문화마을16.7/55.2, BIFF광장10.8/55.5. **조사연도·표본·기준이 달라 차감해 미인지율을 계산할 수 없음.** [국내 조사](https://www.busan.go.kr/opinion/1717379) / [해외 조사](https://www.yna.co.kr/view/AKR20251205113900051)
- 태종대 내국 방문 **28.1%**, 해동용궁사 **25.6%**. 현재 확인한 외국인 조사에서 해당 장소의 방문 비율을 추출하지 못함. 따라서 **외국인에게 덜 알려졌다고 확정하지 않았으며** 해동용궁사는 기존 해외 관광정보 사이트 조회 선례도 존재함.
- **서울 2025 외국인 유동인구** 명동 일평균100,910명·N서울타워57,370명·홍대40,213명; K-등산 북한산4,015명·아차산729명/일. 아차산 +11.8%, 광장시장 +10.4% 증가. 이미 방문하는 곳은 미인지 대상으로 포장하지 않음. [서울시 보도](https://www.seoul.go.kr/news/news_report.do?nttNo=462041)
- 새로 **검증 후보 24개** 작성. 국가별 외국인 세부 희망과 기존 40개 경험/불편 코드를 잇되 '미인지 확정'은 전부 보류함.

## 실제로 유효한 발견 가설
1. **기존 명소에서 행동 완수**: 광안리·감천·BIFF·성수는 발견보다 메뉴 이해·이동·예약·운영변경 해결.
2. **지역 확장 기회**: 태종대·송정·다대포·속초·안동 등은 한국인 방문/관광자원 증거와 외국인 실제 인지·방문 데이터의 공백을 구분하며 추가 조사.
3. **일상문화 적합성**: 포토부스·편의점 먹거리·한강라면·야구 응원은 한국인이 '직접 즐김' vs '외국인에게 추천' vs 외국인이 '이미 앎'을 각각 따로 검증.
4. **적합성·실행 가능성**: 고궁·전통 한식·계절 체험은 활동의 수요뿐 아니라 일정·예약·언어·이동 등 장애와 함께 실험.

## 조사 설계
한국인과 외국인에게 공통 경험 10~15개를 **같은 사진과 1문장 설명**으로 보여주되:
- 설명하기 전 자유회상 → 설명 없이 장소 인지 여부 → 지난 2년 실제 방문 → 설명 후 매력도와 체험 의향 → 한국인은 *외국인에게 추천할지* 별도 질문 → 동선·결제·예약·언어 어려움.
- 국가/연령/방문횟수는 선택적 배경, 성별 강제 불가. 장소 노출 순서 무작위화.
- 비교 지표: 내국 추천 의향률, 외국 사전 인지도, 외국 설명 후 4~5점 매력도, 실제 과업 완수율. **소규모 시범 응답은 모집단 대표성이나 인과효과를 증명하지 않음.**
- 표준 설문과 모집 절차는 `matched-survey-protocol-v0.3.md`.
