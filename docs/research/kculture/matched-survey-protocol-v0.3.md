# 한국인·외국인 로컬 경험 동일 문항 조사 프로토콜 v0.3

**목적**: '한국인이 외국인에게 추천하고 싶어 하지만 외국인은 아직 잘 모르는 경험'을 **실제로 검증**하기 위한 소규모 시범조사. 관심 수요·인지·이용 경험·추천 의향·실행 어려움을 구분한다.

## 모집
- 집단A: 한국 거주자(한국 문화 체험·국내여행 경험자 포함)
- 집단B: 외국인 중 방한 경험자
- 집단C: 방한 경험은 없지만 방문에 관심 있는 외국인
- 시범 모집 목표 예시: 집단별 20~30명. **편의표본이므로 한국인/외국인 전체로 일반화 금지**. 결과 공개 때 실제 표본·모집경로·연령·국가 및 응답 누락률 공표.
- 국적만으로 사용자의 취향을 추론하거나 성별/민감정보를 필수로 요구하지 않는다.

## 순서 및 문항
1. **중립 설명 전**: '한국 여행 또는 문화 경험 중 생각나는 장소/활동 3개는?' 자유응답.
2. 무작위 순서로 10~15개 공통 체험명을 제시. '이름을 들어봤는가?' (전혀 모름 / 들어만 봄 / 내용을 알고 있음).
3. 해당 경험의 최근 2년 실제 참여/방문 여부 (있음/없음/기억안남).
4. 한국인에만: '외국인 친구에게 추천할 경험 최대 5개'와 '본인이 즐기는 경험 최대 5개' **별도 질문**.
5. 외국인에만: '한국 방문 계획에 실제로 넣고 싶은 것 최대 5개'.
6. 모두에게 번역 검수한 동일한 1줄 설명·가능하면 동일한 사진을 보여주고 '설명 후 경험 매력도 1~5점'.
7. '예약·현장소통·교통·가격·운영정보·결제·취향 불일치 중 무엇이 어렵나?' 최대 3개.
8. 선택형 배경: 방문횟수/연령대/관심 주제/거주국·체류지역. 개인신원·연락처를 응답과 결합하지 않음.

## 지표
- 한국인 실제 즐김률: 즐긴다고 응답 / 항목별 내국 응답자
- 한국인 해외 추천 의향률: 추천 대상으로 선택 / 항목별 내국 응답자
- 외국인 무보조 인지율: 자유기입에서 발견한 응답자 / 외국 응답자 (표기어 동의어 정규화)
- 외국인 사전 인지도: 설명 전 알고 있음 응답 / 외국 응답자
- 외국인 매력도: 설명 후 4~5점 응답 / 항목별 외국 응답자
- 외국인 실제 방문 경험: 참여 응답 / 방문경험자 중 해당 문항 유효응답

'추천 높음, 사전 인지도 낮음, 설명 후 매력도 높음'은 **추가 검증 우선 후보 분류**일 뿐 통계적 격차가 입증됐다는 뜻이 아니다. 표본수가 충분하면 구간·표준오차를 포함하며 국가·방한경험·노출경로를 나누어 본다.

## UX 비교
- 동일 과업: 새 경험 찾기 → 시간/가격/장소 확인 → 이동/예약 또는 실제 주문 실행.
- 비교군: 기존 GPT+지도+현행 예약 서비스 조합.
- KoreaMate: For You/New to You/기존 전문 Studio와 통합한 정보 연결안.
- 성공률, 단계수, 완료시간, 정보 오류, 사용자가 기대한 새 경험 발견 여부, 후속 사용 의도를 구분 측정.
- 실험 전 특정 KPI 우월성을 미리 가정하지 않는다.

## 후보
부산 태종대·해동용궁사·다대포·이기대, 서울 한강 라면·성수 팝업·아차산, 지역 속초시장·안동 등은 **외국인 인지 미확인 여부가 서로 다름**. 이미 외국인 유동인구가 관측된 곳은 숨은 장소로 취급하지 않는다.
