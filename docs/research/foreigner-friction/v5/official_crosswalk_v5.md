따라서 실제 표본수·방한 의향률·문화경험률 등은 결측으로 유지한다. 26개 거주국과 상위 5개 방문 의향 지역이라는 안내만으로 응답자 분모나 수치를 만들지 않는다. 원자료 신청이나 이메일 발송은 하지 않았다.

# 서비스 조건 교차확인 — 2026-10-18

공개 안내문을 읽어 특정 조건을 확인했다. 이용자 사건이 실제 발생했는지, 카드 결제·예약을 재현했는지와 별개다. 사례의 current_policy_verified를 일괄 YES로 바꾸지 않는다.

## 블루라인파크 예약 오픈·현장표
https://www.bluelinepark.com/eng/booking.do

예약 안내에는 화요일07:00에4주 후 월~일의 표가 열린다고 명시되어 있다. 제한된 현장표는 선착순이며 조기 매진 가능하다고 설명한다. 따라서 늦게 예약 시도해 원하는 시간대를 놓친 사례와 현장표로 회복한 사례가 함께 존재할 수 있다. 특정 카드 인증오류의 원인은 확인되지 않았다. One Flight Out의 달력 날짜·요일 불일치는 그대로 주의사항에 보존한다.

## k.ride의 외국인 이용 경로
https://www.kakaomobility.com/k-ride

사업자 서비스 소개는 Google·Apple·이메일 가입, 해외 발급 카드 및 일부 간편결제, 다국어 목적지 검색·채팅을 안내한다. 따라서 한국전화번호·한국카드 없이는 모든 택시앱 이용이 불가능하다는 일반화는 지지되지 않는다. 특정 단말·계정·차량 호출의 실제 성공률이나 사용자 오류 원인은 미확인이다. Kakao T와 k.ride를 같은 서비스 흐름으로 합치지 않는다.

## Catchtable Global의 대안 경로
https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=205615

한국관광공사2024-09-23 안내는 한국전화번호 없이 Google·Apple 계정 가입, 해외카드 결제와 예약·대기 기능을 설명한다. 원격대기·현장대기는 매장에 따라 다르다. 읽은 자료는 과거 공식 안내이며 현재 모든 매장 지원을 보증하지 않는다. 국내판 Catchtable의 실패와 글로벌판 성공을 합쳐 모순이나 전면해결로 판단하지 않는다.

## 제품 해석
이미 이용 가능한 외국인 경로를 발견·준비·복구하도록 돕는 기회는 관찰된다. 그러나 모든 사업자의 실시간 연동이나 대리예약이 가능하다는 증거는 아니다. 제품 구현·사업자 연동·P0 변경은 이 연구 산출물에서 결정하지 않는다.

## 결론
18개 후보를 source_register.csv에 정리했다. 해외 기관의 독립 조사와 Kaggle/Hugging Face/Zenodo에 올라간 한국 원천자료를 구분했다. 이번 탐색에서 **한국 여행 중 외국인이 겪은 불편을 행 단위로 확인하면서, 언어·국적·날짜·원문 링크까지 함께 갖춘 즉시 재사용 가능한 공개 데이터셋은 확인하지 못했다.** 이는 존재하지 않는다는 결론이 아니다. 현재 원문 사례 수집을 대체하거나 그 건수를 부풀릴 근거로 사용하면 안 된다.

## 바로 가치가 있는 세 갈래
1. 실제 한국 숙박 후기: [Kaggle Booking.com hotel review](https://www.kaggle.com/datasets/frogsohyun/bookingcom-hotel-review). 직접 다운로드한 36,669행, 호텔명 438개. 모든 후기에서 한글을 검출했다. 국적·원어·번역 여부·작성일·리뷰 URL이 없으므로 '외국인 후기 36,669건'이라고 부를 수 없다. 숙박 불편 코딩 체계의 보조자료로 적합. CC BY-NC 4.0이므로 상업적 활용 권한을 별도 확인해야 한다.
2. 방한 불편 비교 연구: [야놀자리서치 Vol.41](https://www.yanolja-research.com/insight/view/752?lang=en). Purdue 연구자 참여. 2023–2025년 영어 Reddit 글의 한국 3,480/일본 3,780개 문단을 분석. 디지털·정보안내·교통·결제 비중 69.3%라는 결과는 본 연구의 분류체계를 교차검토하는 데 유용하다. 웹 본문과 한/영 PDF는 있으나 원자료 파일·행 스키마·데이터 재사용 라이선스는 확인하지 못했다. 수치는 방문객 비율이 아닌 선택된 불편 데이터의 구성비이며, 문단 수는 독립 인원 수가 아니다.
3. 해외 연구 질문 자료: [IIT Delhi TourismQA](https://github.com/dair-iitd/TourismQA). 논문은 47,124개의 실제 여행 질문을 보고한다. 직접 받은 50개 도시 설정에 Seoul이 있다. 다만 설정 파일이 한국 질문의 실제 포함을 보장하지 않는다. 저장소는 원문 전체보다 URL/정답 엔티티 매핑과 재수집 코드를 제공한다. 일부 API가 깨졌다고 명시한다. 매핑 목록 추가 확인 중 GitHub API가 403 rate limit을 반환하여 중단했다. 공개된 질문 수와 한국 하위집합 수를 혼동하지 말 것.

## 실파일 검증에서 발견한 오해 위험
- [CMU 원본 TripAdvisor 자료](https://www.cs.cmu.edu/~jiweil/html/hotel-review.html): 878,561건/4,333호텔로 유명하지만, 내려받은 offering.txt 4,333행은 미국 25개 도시뿐이다. 한국 웰니스 연구에 이를 '세계 호텔/한국 호텔 필터링 가능'하다고 소개한 [2026 논문](https://link.springer.com/article/10.1007/s10791-026-10204-y)의 설명은 원본 호텔 메타데이터와 맞지 않는다. 한국 사례 근거로 채택하지 않는다. Kaggle의 업데이트 연도 역시 후기 작성 연도가 아니다.
- [Zenodo MMCA 설문](https://zenodo.org/records/15124049): 설명은 1,705명이나 CSV는 1,691행. 거주지는 모두 한국 시도이며 국적 열은 없다. Groningen·중앙대 공동연구이고 CC BY 4.0이다. 불편, 안내 이해도, 앱·로봇 UX 문항은 유용하지만 방한 외국인 표본이라고 해석할 수 없다. CSV 시간대 표기는 EET여서 현지 수집시간으로 바로 해석하지 않는다.
- [Kaggle South Korea Visitors](https://www.kaggle.com/datasets/bappekim/south-korea-visitors): 2019-01~2020-04 월·국가 집계. 각 960행의 세 파일은 연령/성별/목적별로 같은 유입량을 나누므로 2,880개의 독립 사례가 아니다. KTO 재가공본이며 CC BY-SA 4.0. 경험 원문은 없다.
- [UCI Travel Reviews](https://archive.ics.uci.edu/dataset/484/travel+reviews)는 이름과 달리 980명의 관광 범주별 평균점수다. 원문·국가·방문일이 없어 불편 원인 연구에 부적합하다.
- Rosetta 관광 QA는 합성 자료. KR3/POI는 한국어 감성분류 자료. 한국 배송 앱 자료의 영어판은 번역본. 영어라고 외국인이 쓴 글로 간주하면 안 된다.

## 범위와 접근 검증
- Kaggle: 공개 landing page뿐 아니라 public API metadata로 설명·라이선스를 확인했다. 한국 Booking.com 후기, South Korea Visitors 세 CSV, Korean Hotel Dataset CSV는 실제 다운로드·행/열 검증 완료. 후보 검색어는 Korea, Seoul, Korean reviews, Korea tourism, Korea hotel, hotel reviews 등.
- Hugging Face: KR3, jniimi Tripadvisor, Rosetta 카드/뷰어 확인. jniimi는 CMU 자료의 영어 필터링 파생본이며 한국 데이터가 아니다.
- Zenodo: MMCA CSV·메타데이터 확인, KTS 파일목록·메타데이터 확인. KTS는 Zenodo MIT 표기와 GitHub all-rights-reserved 문구가 함께 있어 권리 확인 필요. 3.6GB 이미지 묶음은 내려받지 않았다.
- HotelRec: 실제 SWITCH Drive 링크가 Full_HotelRec.zip으로 열림. README는 학술연구 전용. 한국 하위집합은 검증되지 않았고 상업적 사용 가능하다고 안내하면 안 된다. 대용량 파일은 다운로드하지 않았다.
- OSF·Harvard Dataverse: 한국 관광·tourist·review 조합의 검색에서 본 목적에 맞는 공개 원문 데이터 landing page를 확인하지 못했다. 저장소 전체를 전수 조사한 것은 아니다.
- 서울 관광지·호텔 논문: 실제 연구 데이터 규모와 스키마는 보이지만 공개 원자료는 확인하지 못해 '논문 집계'로 분리했다. MDPI 직접 열기 실패 시 검색 색인에서 확인한 부분은 검증 등급을 낮췄다.

## 다음 분석에 적용할 규칙
1. 해외기관 수집/한국기관 수집/해외 플랫폼 호스팅을 따로 기록한다.
2. 경험 원문, 설문 미시자료, 관광통계, 논문 집계, 합성자료를 같은 분모로 합치지 않는다.
3. 독립 출처는 플랫폼과 데이터 계보로 판별한다. CMU→Kaggle→Hugging Face는 세 독립 표본이 아니다.
4. 출발국·국적·거주지·작성 언어를 서로 대체하지 않는다. 일본어·중국어·동남아 언어의 한국 방문 불편 데이터 공백은 여전히 남아 있다.
5. 원문 사례 수를 늘리려면 한국 방문 맥락, 실제 경험인지, 게시일, 원문 링크, 중복 여부를 다시 검증해야 한다. 질문은 불편 경험과 별도 구분한다.
6. 저장소 표기 라이선스가 원 플랫폼의 저작권·개인정보·상업 이용 조건까지 해결해 준다고 가정하지 않는다. 원문 대량 재배포보다 문제 유형·짧은 근거·검증 링크 중심으로 공유한다.
