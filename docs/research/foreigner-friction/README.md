## 기존 KoreaMate와의 연결

원래 목적은 **① 모르니까 못한다 ② 알아도 하기 어렵다 ③ 정보·서비스가 흩어져 있다**를 해소하며, 한국 문화를 취향과 상황에 맞춰 발견하게 하는 것이다. 새 자료는 Scan Anything 하나에 문제 해결을 맡기지 않고 **Travel Prepare, AI Mate, Service Connector, Help Me Now, Plan B, My Korea**의 역할을 관측된 과제 단위로 재검토하기 위한 근거다.

## 주의사항

1. **자기선택 편향:** 불편을 느낀 사람·질문이 있는 사람이 온라인에 더 많이 글을 남긴다. 이 표본의 장벽별 건수로 관광객 불편 발생률이나 기능 수요 순위를 주장하면 안 된다.
2. **질문≠실패:** 해외카드가 될지 걱정하는 질문과 실제 결제 거절은 다른 증거이다.
3. **사용자 진술≠현행 서비스 정책:** 전화번호·인증·결제·교통카드 규칙은 서비스·시점마다 달라졌다. 반드시 현재 공식 출처에서 재검증해야 한다.
4. **링크 중복:** 같은 글의 서로 다른 문제 사건은 별개의 case_id로 두되 동일 source_id와 URL을 사용한다. 집계 시 사건 수와 독립 출처 수를 구분한다.
5. **개인정보:** 닉네임·IP·연락처·정확한 개인 일정·제삼자의 민감 정보를 데이터에 수집하지 않고 짧은 한국어 요약과 URL만 보관한다.
6. **서비스 지원의 범위:** 본인인증·결제의 제약을 우회하거나 예약 완료로 가장하지 않는다. 공식적으로 허용된 경로·확인 가능한 대안과 사용자 과제 평가에 한정한다.
7. **영상:** YouTube 후보는 설명만 본 상태이므로 특정 장면의 직접 경험으로 코딩하지 않는다. 전사·댓글을 보려면 실제 영상과 제공 조건을 검토한다.

**기준 문서 변경 금지:** 이 연구 자체로 서비스 P0나 팀 개발 범위를 확정하지 않는다. 사용자 과제·공식 근거가 누적된 뒤 별도의 의사결정에 반영한다.
