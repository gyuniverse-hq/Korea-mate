## 검수 범위 및 정확한 분모

- 기존 CSV: **47건 / 고유 URL 46개**. 스키마·사건 ID·원천 연결·URL 중복을 구조적으로 확인. 최초 분류는 **전건 1인 코딩**이며 독립적 원문 전문 재분류 완료 0건. 종전 원문을 검증 완료로 승격시키지 않음.
- 신규: **27건 / 고유 URL 20개**. 게시글 원문 또는 해당 원문에서 조회되는 댓글을 읽고 한국어로 재기술한 **1인 원천대조 관측**. 증언 진위·현재 공급자 정책은 검증하지 않음.
- 누적: **74사건 / 고유 UGC URL 66개**. 기존 출처 등록 55개 + 신규 20개 = 75개(공식 자료·영상 후보 포함).
- 신규 언어: en 14건 / zh-Hant 7건 / ja 6건. 신규 성격: FRICTION 11 / MIXED 2 / CONCERN 9 / POSITIVE 5. 증거: FIRSTHAND 12 / COMMENT_FIRSTHAND 7 / QUESTION 8.
- 신규 장벽 코드: IDENTITY 3, EMERGENCY_RECOVERY 2, ONSITE_USABILITY 3, TRANSPORT 1, LANGUAGE 3, BOOKING 2, PAYMENT 5, TAX_REFUND 3, PREPARATION 4, CULTURAL_RULES 1. 이는 **조사한 기록의 분포**일 뿐 외국인 전체 발생 빈도가 아님.

## 자동 구조검사

- 사건 ID 중복: 0, 기존 대비 신규 URL 충돌: **0개**, 기존 원천 등록 연결 누락: 0.
- 의도된 복수사건/URL: 기존 KM-FR-010/011과 신규 같은 글의 다른 과제 또는 별도 댓글 증언. source_id를 공유. 동일인이 여러 앱에서 한 목표를 시도한 경우는 억지 분할하지 않음(KM-FR-048).
- 기존 47건 모두 원래 INITIAL_SINGLE_CODER 유지. 새 27건은 SINGLE_REVIEW_V2. **DOUBLE_CODED / ADJUDICATED 0건.**
- 게시일 ≠ 실제 사건 날짜. 2025-01-01 이전 기록은 역사 사례로 유지하고 현재 정책 주장에 이용하지 않음.
- 기존 `KM-FR-047`은 관광 대상 아님 가능성이 커 SCOPE_REVIEW. 기존 파일에서 삭제하지 않았으며 관광에 해당하는 문제별 계산에서는 보류.
- 신규 직접 원문 대조는 공개 페이지의 게시글·일부 답변에 대한 확인만 의미. 실거래 재연·응답자 신원 확인·법규 확정·원본 전체 댓글 전수검사는 아니다.

## 중요한 보정/보류

1. **정책이 정답이 아님:** 국내번호, 실명 인증, 외국 카드, 환급은 플랫폼·날짜·상품에 따라 다름. AI가 정책을 추측하면 소스-증언 상태와 공급자-현행 정책 상태를 혼동하는 오류.
2. **반례:** 실제 전자지도/결제/식당 주문/공연 예매 성공 기록을 별도 POSITIVE로 유지. 질문·직원 조언을 실패로 계산하지 않음.
3. **민감 정보 배제:** 닉네임·IP·주소·건강상세·신분증·전화번호를 수집하지 않음. 새 텍스트는 한두 문장 원문 의역 및 원 URL만 보관.
4. **기존 파일 누락:** 구 README가 가리키던 `pilot_counts.json`, `scripts/build_seed.py`, `scripts/validate_cases.py`, `KoreaMate_Friction_Pilot_v1.0.xlsx`는 조사 브랜치에서 실제 파일 목록을 재확인해야 함. 본 v2 산출물은 실재하는 파일만 링크.
5. **언어 불균형:** 영어/Reddit 과대표집과 일본·중국어 편의표집이 남음. 추가 언어(베트남어·태국어·인도네시아어)는 직접 검증된 관광 게시글이 부족하므로 0건을 있는 그대로 기록.
6. **영상 0건:** 설명·제목만 확인한 유튜브 후보를 사건으로 승격하지 않음.
