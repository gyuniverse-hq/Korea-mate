### 기존 EDA에서 새 연구에 연결할 질문

- 사전 고려한 K-pop 관련 장소/미용서비스 미참여율(각 28.1%, 35.8%)은 **직접 중단 원인이 아님**. 참여자 vs 미참여자의 정보 부족 차이는 인과 증거가 아님.
- 사후 '정보 부족 없음' 응답이 전체 약 절반으로 보고돼 **모든 관광객이 정보 부족**이라는 주장과 충돌.
- 추천 모델 테스트 NDCG@3 개선은 설문에서 실제 방문한 활동 분류를 잘 예측한 것이며 제품 내 추천 클릭/방문 전환 향상 검증 아님.
- 사용자 실제 SNS→지도→예약 경로, 본인확인 실패 단계, 여행 후 복구 비용, 앱간 맥락 유지 여부는 공식 설문에 직접 변수 없음. UGC/사용자과제로 측정.

### 공식 자료에서 이번에 하지 않은 일

잠재 방문 조사 PDF 원문·전체 집계 수치 다운로드, 1330 유형별 실제 숫자 추출, 한류 최신 검색량 실제 값 다운로드, 별도 법규·공식 사업자 약관 전수 확인 **미완료**. 이를 수행한 것처럼 기술하거나 빈 숫자를 채우지 않음.
