### 새로운 관찰의 의미

1. 'Scan Anything'은 메뉴 화면을 읽어도 **여권 긴급 대응, 막차, 환급 자격, 계정 권한**을 해결하지 못함. 해결 주체와 정보 원천이 서로 다르기 때문.
2. 통합 여행 동반자 가설을 강화할 관측도 있으나 실제 맥락 유지 가치가 실증된 것은 아님. 측정할 사용자 과업: `상황 설명 횟수`, `공식 경로까지 걸린 단계`, `현재 이용 가능한 대안 적중률`, `확인되지 않은 완료 주장률`.
3. '기능이 있으면 좋다'와 '직접 구현 추천'을 분리. 긴급 대응·결제·환급은 공식 정보 연결과 불확실성 표시가 현실적이며, 법적 자격/성공을 대리 보증하지 않음.
4. `For You/New to You` 가치는 불편 해결뿐 아니라 성공·반례 사용자에게도 의미가 있는지 추가 수집할 질문. 이번에는 문화 발견 실제 비참여 원인의 직접 증거가 부족.
