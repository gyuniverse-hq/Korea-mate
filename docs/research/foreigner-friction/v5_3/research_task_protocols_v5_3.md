# KoreaMate v5.3 연구 과업 6개 — 제품 P0 미확정

같은 목표·동등한 자료·조건 순서 교차로 기존 서비스만 사용하는 조건과 가설적 지원 조건을 비교한다. 아래는 연구 제안이며 실제 실험을 실시했다는 의미가 아니다.

| 과업 | 비교 | 측정 | 필수 제약 |
|---|---|---|---|
| E1 예약·인증·글로벌 이용 경로 | 공식 예약 사이트 자력 탐색 vs 근거가 표시된 허용 경로 안내 | 정확 경로 도달, 잘못된 완료 확정 수, 소요시간 | 사전 허용된 시뮬레이션; 무단 실제 결제/가입 금지 |
| E2 SNS·지도·현장 이동 맥락 | 기존 여러 앱 vs 취향·시간·짐·교통 조건을 유지하는 지원 | 재입력 횟수, 앱 전환, 경로 정확도, 시간 | 접근성 확인 없을 때 이용 보장 금지 |
| E3 한국어 주문·현장 규칙 | 번역만 제공 vs 메뉴/최소주문/수량 안내 | 목표 주문 완료율, 추가 확인 횟수, 오역·과다주문 | 알레르기 등 식품 안전 보증 금지 |
| E4 휴무·날씨·일정 변경 복구 | 기존 검색 vs 공식 최신 운영 확인과 남은 일정 재계획 | 유효 대안 정확도, 운영정보 오답, 시간제약 위반 | 실시간 정보 없으면 불확실 표시 |
| E5 분실·환급·긴급 대응 | 공식기관 안내·서류·접수/완료 판별 과제 | 정확한 근거, 허위 완료 주장, 개인정보 최소 수집 | 긴급 신고/환급 자동 대리 불허 |
| E6 새로운 문화 체험 발견 | 재방문/비K-pop 취향 이용자 기존 검색 vs 제안된 발견 흐름 | 새 경험 적합성, 실제 이용 가능, 불필요 권유 | 기존 서비스만으로 만족한 대조군 포함 |

원문 기반 실패·긍정 반례를 함께 선별하고, 사용자의 거주/방문 상태·언어·디지털 익숙함·일정 제약을 확인한다. 현재 서비스 정책과 사용자 과업 완수는 별도의 근거로 기록한다. 성공한 공식 경로도 그대로 인정하며 연구 결과를 팀의 우선순위에 자동 적용하지 않는다.
