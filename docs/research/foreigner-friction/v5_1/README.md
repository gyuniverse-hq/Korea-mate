## 데이터 버전 규칙

- [v5 원본 407행](../v5/cases_cumulative_v5.csv) **70개 원본 열 그대로 보존**. 본 패키지의 `cases_cumulative_v5_1.csv`는 5개의 `v5_1_` 열만 덧붙여 원자료와 최신 검증 판정을 같이 읽는 *분석용 뷰*.
- v5 인계: 직접경험 예비303, 질문수요61, 출처대기18, 역사20, 기타5. v5.1: **직접경험 예비304 / 출처대기17** (그 외 동일).
- 격상은 `KM-FR-128` **단 1건**. 일본 Yahoo 공개 원문을 실제 확인했고 당사자의 여행 중 환승 개찰구 오류 및 우회 통과가 서술되어 있음. 진위·최신 교통정책은 검증하지 않음.
- 직접경험 304개 행은 **157개 원천 군집**에 속하며 304명·304개 독립 검증 완료를 뜻하지 않음.
- `USER_SCOPE_UNCERTAIN` 3건은 원문에서 사건 진술을 확인했어도 관광/체류자격을 확정하지 못하여 계속 보류.
- **사업자 현행 정책 적용 검증 0건, 사건 자체 독립 진위 검증 0건**. 2차 검수도 v5와 동일하게 비맹검·목적표집이므로 일치도 추정 금지.
