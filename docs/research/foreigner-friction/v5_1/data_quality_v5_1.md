- **사건 ID 중복 0**; 기존 407행의 순서·모든 v5 원본 필드 보존(새 열 5개 추가).
- v5 직접경험 예비 **303 → v5.1 304**, 출처 대기 **18 → 17**, 질문 61·역사 20·대상 불명3·전언1·인접범위 제외1 모두 그대로. 전체 **407행 유지**.
- 직접경험 예비 304행이 157개의 출처 군집에 묶여 있어 독립 작성자 수 304명과 같지 않음.

## 이번 확인 사례

**KM-FR-128**: [일본 Yahoo 질문 원문](https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q12327406682), 2026-04-20 작성. 본인은 한국 여행 중 귀국길에 신논현역 T-money 개찰구 오류를 겪고 약 20분 다른 개찰구를 찾은 뒤 통과했다고 기록. 2026-04-22 후속 질의도 확인. 작성자의 **진술과 작성 위치**에 대한 확인이지 철도 시스템의 공식 오류 사유를 확인한 것이 아님. `PENDING_SOURCE → DIRECT_EXPERIENCE_PRELIMINARY` (원문 접근 `ORIGINAL_BODY_OR_AUTHOR_ARCHIVE`). 결과 WORKAROUND는 이전 그대로.

## 유지한 불명·보류

- **KM-FR-135**: 일본 번호 CatchTable 가입 실패 자체는 직접 원문 확인, 저자에게 방한 관광객 지위가 명시되지 않으므로 USER_SCOPE_UNCERTAIN 유지. 글로벌 앱 정보는 제3자 답변이며 본인의 등록 성공 증거 아님.
- **KM-FR-332**: SAS의 광명역 수속 실패는 독립 댓글 당사자 진술로 확인, *작성자 여행 목적·거주상태 불명* → 보류.
- **KM-FR-339**: 한국에서 샤인머스캣 묶음 구매는 당사자 댓글로 확인, *한국 단기 관광과의 직접 연결 불명* → 보류.
- Reddit 원문 6개는 다시 열었으나 Cache miss, note 일본 여행기 4행의 원문은 Cache miss. 이전 출처 대기 상태 그대로 유지. 태국 Pantip 원문 재시도는 기존 안전하지 않은 리디렉션 이력 때문에 이번 실행에서 수행하지 않음. YouTube 원본 직접 시청은 이번 단계 수행하지 않음.

## 검토 방법의 한계

- v5 기존 229행의 과거 검토 중 46행은 제2 검토자의 **비맹검·목적표집 원문 비교**다. 이번 작업이 맹검 코딩 또는 독립 사건 발생 사실 검증을 추가한 것은 아님.
- 본문에 없는 원인 추정, 실제 결제·탑승 완료 추정, 댓글 작성자의 관광객 신분 추정 금지.
- 구조 검증은 자료 품질의 최소 조건. 원문 전체/모든 댓글 무결성/법규/현재 이용 정책 검증률로 혼동하지 않음.
- 출처 URL 239개와 source_cluster 간의 원천 중복·같은 작성자 교차게시 가능성이 남음. **사건 행 수/고유 URL 수/작성자 수/독립 사건 수를 서로 대체하지 않음.**
