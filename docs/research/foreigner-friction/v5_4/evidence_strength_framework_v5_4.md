# v5.4 근거 강도와 주장 범위

**두 축을 따로 판단한다.** 공식 데이터라 하더라도 제품의 개선 효과를 증명하지 않으며, 원문을 직접 읽어도 사건 진위나 현재 정책이 자동으로 입증되는 것은 아니다.

| 출처 강도 | 확인 가능한 내용 | 불가능한 확정 |
|---|---|---|
| official_aggregate | 해당 문항·모집단·상담 기간의 집계값 | 개별 서비스 장애율·인과 효과 |
| reproduced_count/coding | 저장된 407행과 결과·코드·157 출처군집의 재현 가능한 구성 | 방문자 수·시장 발생률 |
| primary_selfreport | 저자의 실제 자기보고 원문 | 사건 진위 재현·현재 서비스 규정 |
| indexed_or_mixed | 확인된 일부 인용·색인·댓글 | 전체 문맥·최종 결과 |
| unmeasured | 실험·연동을 통해 검증할 가설 | 이미 효과가 검증됐다는 주장 |

각 주장에 조건부(conditional)·직접(direct)·코딩(coded)·자기보고(reported)·미검증(untested) 범위를 기록한다.

139, 304 등의 숫자는 독립 관광객을 뜻하지 않는다. PRE(사전 태도), VOC(관광안내 건수), UGC(개별 사건 행)는 모집단·측정 단위가 다르므로 합산할 수 없다. 문화 발견의 긍정 반례도 보존하고 P0·BM·서비스 기획은 별도 결정한다.
