## 1. 이번 작업에서 먼저 정리할 것

KoreaMate를 중심으로 진행한다는 전제에서, **KoreaMate 자체의 핵심 경험이 메인에서 선명하게 드러나도록 먼저 설계한다.** 전문 아이템은 사용자가 있고 콘텐츠가 쌓인 상태를 가정하여 인기 결과를 보여주고, 각각의 전문 경험으로 바로 들어갈 수 있게 한다.

원안의 제품 약속은 “한국을 몰라도, 한국을 제대로 즐길 수 있도록.”이다. 이를 구체적으로 만드는 경험은 **Korea Pulse, For You + New to You, Korea 101, See it → Live it, Scan Anything**이다. 이번 설계의 중심은 이 다섯 경험이며, 사용자가 원하는 곳에서 시작하도록 한다. [원안 근거](./service-experience-v0.5.md#b-원래-koreamate에서-절대-놓치면-안-되는-문제)

여기서 P0는 **이번 기획·화면 재정비에서 먼저 충족할 제품 우선순위**다. 다섯 경험의 사용자 행동과 결과를 정의하고 화면으로 확인하는 것이 목적이다. 추천 모델, 사진 인식, 외부 운영 정보 등의 실제 구현 완료는 후속 개발과 검증에서 따로 기록한다. 평가 문서에서 사용하는 결함 심각도 P0와도 구분한다.

### 이번 대화의 의견을 적용하는 방식

| 의견 | 이번 기준에 반영할 내용 |
|---|---|
| 첫 번째 평가 의견 | 사진 중심의 브랜드 감성 유지, Ask·Scan의 진입 명확화, 전문 경험별 결과 표현, 실제 결과를 개선하는 연결 |
| 두 번째 검토 의견 | 질문하기 전에도 시작할 수 있는 문화 발견, 저장·도움·맥락의 연속성, 모바일 정보량 점검 |
| 사용자의 우선순위 | KoreaMate 자체의 정체성을 먼저 P0로 정리. 각 전문 아이템의 인기 결과는 이를 풍부하게 하는 탐색 재료로 배치 |

여행 준비와 현장 도움은 원안의 공통 역량으로 유지한다. 홈에서 차지할 비중은 사용자의 상황에 따라 조정하고, 기본 메인은 문화 발견과 사진·질문에서 시작하는 경험을 함께 드러낸다.

## 2. 전체 순서와 현재 위치

기존 작업에는 원안 대조, 서비스 구조·정보 구조 초안, 메인 v0.9 시안과 HTML이 있다. 아래는 그 작업물을 바탕으로 진행하는 **이번 재정비의 순서**다. 기존 01~08단계 이력은 [README](./README.md#전체-작업-순서)에 유지한다.

| 순서 | 작업 | 산출물 | 다음 단계로 넘어갈 기준 | 현재 상태 |
|---|---|---|---|---|
| **01 · 현재 결과** | **핵심 경험 P0 기준** | 이 문서 | 다섯 핵심 경험, 전문 아이템, 공통 기능의 역할·결과·검토 기준이 명시됨 | **초안 작성 완료** |

| 04 | 시각 시안 | PC·모바일 기준 시안, 사진·서체·색·밀도 기준 | KoreaMate의 분위기와 행동 우선순위가 함께 드러나며 전문 결과의 형태가 구별됨 | 대기 |
| 05 | 체험형 HTML | 시안과 연결된 브라우저 프로토타입 | 발견·입력·상세·저장·전문 진입 및 주요 실패 상태를 직접 조작 가능 | 대기 |

03단계에서 첫 행동을 이해하기 어렵거나 정보량이 과하면 02단계를 수정한다. 04단계에서 검토 가능한 기준 시안을 만든 뒤 05단계로 옮긴다. 06단계의 사용자 검증은 실제 참여자를 대상으로 진행했을 때만 완료로 표시한다.

**이번 1단계의 완료 상태:** 기준 문서가 검토 가능한 수준으로 작성되었다. 팀의 주제 확정, 기능 채택, 담당자 배정과 구현 완료는 각 의사결정 시점에 별도로 기록한다.

## 3. 다섯 핵심 경험의 P0 기준

다섯 경험은 각각 다른 사용자 필요를 다룬다. 홈에서는 역할에 맞는 영역과 진입점을 배치하고, 관련 기능끼리는 화면을 공유할 수 있다.

| 핵심 경험 | 사용자의 시작 의도 | 홈에서 보이는 것 | 사용자가 얻어야 할 결과 | 이번 화면 설계 완료 기준 |
|---|---|---|---|---|
| **Korea Pulse** | “지금 한국에서는 어떤 문화가 주목받고 있지?” | 주목할 문화 장면, 지금 소개하는 이유, 출처·확인 시점. 행사는 날짜·지역·상태 포함 | 새로운 문화의 흐름을 발견하고 더 알아보거나 관련 경험을 선택 | 어떤 문화인지와 지금 소개하는 이유, 근거와 다음 탐색 행동이 보임. 기간·장소·이용 조건은 해당하는 콘텐츠에 표시 |
| **For You + New to You** | “내 취향에 맞는 것과 몰랐던 것을 보고 싶다.” | 취향에 맞춘 제안과 관심을 넓히는 제안, 각각의 추천 이유 | 좋아할 만한 경험을 고르거나 새로운 문화를 발견 | 두 제안의 이유가 구별되고, 관심 미설정·설정·변경 상태가 정의됨 |
| **Korea 101** | “이런 문화도 있었어? 어떻게 하는 거야?” | PC방·찜질방·한강라면·포토부스 같은 생활문화의 짧은 이야기 | 무엇인지, 어떤 재미가 있는지, 어떻게 이용하는지 이해 | 문화 설명과 이용 방법을 확인한 뒤 저장하거나 체험 정보를 더 볼 수 있음 |
| **See it → Live it** | “사진·SNS에서 본 이것을 나도 해보고 싶다.” | 사진·링크 입력과 ‘본 경험을 해보기’ 예시 | 대상을 확인하고 실제로 할 수 있는 행동·조건·대안을 선택 | 입력 대상 확인 → 설명 → 이용 조건 → 선택 가능한 행동이 이어지고, 불가 상황의 대안이 있음 |
| **Scan Anything** | “눈앞의 메뉴·안내문·상품·포스터를 이해하고 싶다.” | 촬영·이미지 입력과 상황별 예시 | 무엇을 인식했는지 확인하고 번역·문화 설명·현장 행동을 이해 | 인식 영역 또는 대상, 설명, 필요한 행동이 구별되고 오인식 수정·재입력 경로가 있음 |

[다섯 경험의 원안 정의](./service-experience-v0.5.md#b-원래-koreamate에서-절대-놓치면-안-되는-문제)

### Korea Pulse와 K-Season의 역할

Korea Pulse는 지금 주목할 문화의 흐름을 발견하는 경험이다. 음식·생활문화·스타일·콘텐츠 등도 포함할 수 있으며, 지금 소개하는 이유와 근거를 제시한다. K-Season은 날짜·지역·계절 조건을 구체적으로 살펴보는 전문 경험이다. 확보된 행사 데이터는 Pulse의 한 재료로 활용하고, 문화 트렌드와 인기를 표현할 때는 해당 주장에 맞는 출처를 연결한다.

### For You와 New to You의 구별

For You는 사용자가 선택하거나 확인한 관심과 추천을 연결한다. 예를 들어 “드라마에 관심을 선택해서”처럼 이유를 보여준다. New to You는 그 관심에서 한 걸음 넓힌 경험을 제안하고, 무엇이 새로운지 설명한다. 관심사의 인접성·다양성·낯섦을 화면에서 시험하되, EDA가 사용자의 실제 사전 지식까지 측정했다고 해석하지 않는다. [EDA 근거][eda-v2]

첫 방문에는 관심을 선택하지 않고도 문화 탐색을 시작할 수 있게 한다. 관심 정보가 없을 때는 편집 추천 또는 인기 추천이라는 기준을 표시하고, 선택 후 추천 이유와 구성이 어떻게 바뀌는지 비교한다. 직접 선택한 관심사로 추천하는 방식은 이번 화면 설계 가설이며, 기존 설문의 모델 성능과 동일한 것으로 취급하지 않는다. [추천 입력 검토][eda-mid]

### See it → Live it과 Scan의 구별

두 경험은 사진·질문·링크 입력 허브를 공유할 수 있다. 사용자가 ‘해보고 싶다’면 이용 조건과 체험 경로를, ‘이해하고 싶다’면 인식 내용과 현장에서의 해석을 우선 보여준다. 메뉴 이해만으로 목적을 달성할 수 있고, SNS에서 본 체험은 필요한 경우 전문 화면이나 방문 계획으로 이어진다.

## 4. 메인에서 보여줄 우선순위

### 첫 화면에서 이해할 두 가지

1. **지금 한국과 몰랐던 문화를 발견할 수 있다.**
2. **궁금한 사진·SNS·질문을 보여주면 이해와 다음 행동을 도움받는다.**

첫 화면에는 한국 문화의 장면, 짧은 제품 약속, 바로 살펴볼 문화 제안과 사진·질문·공유를 시작할 수 있는 입력 경로를 둔다. 개별 입력 수단의 동시 노출과 1차 강조 방식은 PC·모바일 정보 구조에서 정한다. 사용자가 질문을 준비하지 않아도 볼 것이 있고, 이미 궁금한 것이 있으면 바로 입력할 수 있어야 한다. 기존 v0.7의 문화 발견형 + Ask·Scan + 전문 체험 진입 권고를 이번 P0 기준으로 구체화한다. [메인 방향 근거](./home-options-v0.7.md)

### 02단계에서 구체화할 메인 영역

| 역할 | 다룰 내용 | 다음 설계에서 확인할 것 |
|---|---|---|
| **문화 발견의 주 영역** | For You·New to You, Korea Pulse, Korea 101 | 각 추천의 이유와 읽고·보고·해볼 결과가 구별되는가 |
| **즉시 입력** | Ask·Scan·사진·링크 | 입력 목적과 결과가 분명하고 발견 콘텐츠와 함께 사용 가능한가 |
| **전문 경험으로 확장** | 각 아이템의 인기 결과 미리보기와 직접 진입 | 결과 자체에 흥미가 생기고, 어떤 전문 기능인지 알 수 있는가 |
| **개인 맥락과 도움** | My Korea, 준비·현장 도움·Plan B | 이전 선택을 이어가거나 필요할 때 도움을 받을 수 있는가 |

이 표는 역할의 우선순위다. **세로 배치 순서·영역 수·높이·카드 수는 02~03단계에서 정한다.** 다섯 핵심 경험을 동일한 다섯 구획으로 반복할 필요는 없다. 예를 들어 Korea 101은 짧은 이야기, Pulse는 시기성 있는 편집, Scan은 입력과 결과 중심으로 표현한다.

## 5. 전문 아이템의 인기 결과를 연결하는 방식

**설계 가정:** 각 아이템에는 사용자와 콘텐츠가 있으며, 그 안에서 인기 있는 결과를 선정해 메인에 보여줄 수 있다. 먼저 이 상태의 화면을 설계한다. 실제 인기 집계 방식은 콘텐츠·로그가 연결되는 구현 단계에서 구체화한다.

메인에서 전달할 순서는 **흥미로운 결과 → 제공하는 전문 아이템 → 바로 체험하기**다. 전문 아이템의 이름을 이미 아는 사용자는 탐색 메뉴나 직접 링크로 바로 들어갈 수 있다.

| 전문 아이템 예시 | 인기 결과로 보여줄 내용 | 바로 할 수 있는 행동 | 독립적으로 완결되는 결과 |
|---|---|---|---|
| **Kravel** | 작품 기반 촬영지 코스, 주요 장면·방문지·소요 시간 | 코스 살펴보기·편집 | 촬영지 코스 저장 |
| **K-Beauty** | 인기 룩, 스타일 비교, 관련 제품 조합 | 룩 체험·비교 | 룩·제품 후보 저장 |
| **K-Season** | 날짜와 지역에 맞는 행사·계절 경험 | 달력·방문 조건 보기 | 행사 후보 저장 |
| **K-Class Learner** | 관심을 끄는 영상 장면과 배울 표현 | 짧은 학습 시작 | 학습 결과·복습 기록 |
| **GG Korea Fan** | 팀·선수와 연결된 팬 경험·경기·행사 | 팬 경험 살펴보기 | 팬 경험 후보·코스 저장 |
| **여행자용 Food 등** | 음식문화·메뉴·체험 콘텐츠 | 메뉴 이해·체험 정보 확인 | 이해·선택·주문 보조 |

위 아이템은 기존 문서의 후보를 사용한 표현 예시다. 개별 아이템의 채택과 상세 개발 순서는 팀 의사결정 시 별도로 정한다. [전문 경험과 독립 결과의 근거](./service-experience-v0.5.md#e-대표-경험signature-experience-정의)

**인기의 단위를 구별한다.** ‘KoreaMate 전체 인기’, ‘Kravel 내부 인기 코스’, ‘내 취향에 맞는 제안’은 각각 다른 선택 기준이다. 서로 다른 아이템을 하나의 종합 순위로 경쟁시키기보다, 아이템 안의 대표 결과를 발견하고 선택하게 한다. 시안의 순위 예시는 화면 전체의 시연 안내로 가정을 설명하며, 실제 적용 시에는 이용·저장 등 집계 기준과 기간을 연결한다.

같은 콘텐츠가 여러 영역에 등장할 때도 소개 이유를 유지한다. K-Season의 한 행사를 Pulse에선 ‘곧 시작’, For You에선 ‘선택한 공연 관심’, 전문 결과 영역에선 ‘K-Season 안에서 인기’라는 기준으로 소개할 수 있다. 한 화면의 중복 노출은 02단계에서 조정한다.

K-Class Tutor, GG Pro, 기업용 K-Food Market 등 다른 목표 사용자의 아이디어는 기존 별도 모드·생태계 후보 지위를 유지한다. 이번 여행자용 메인에 노출하는 기준이 곧 해당 아이디어의 제외 결정은 아니다. [서비스 계층 근거](./service-experience-v0.5.md#c-새-서비스-구조--네-개의-층으로-분리)

## 6. 공통 기능이 이어줄 사용자 맥락

## 8. 후속 화면에서 확인할 대표 과제

다섯 경험을 여러 시작점으로 확인한다. 아래 과제를 03단계 화면 초안과 05단계 HTML의 검토에 사용하고, 준비된 범위에 맞춰 06단계에서 사용자에게 실제 수행을 요청한다. 전문 경험·융합 과제는 02단계에서 인기 결과 미리보기·직접 진입, 대표 체험 시연, 실제 기능 연동 중 이번에 검증할 수준을 명시한다. 후보 아이템 전체의 상세 구현을 이번 메인 HTML의 완료 조건으로 확정하지 않는다.

| 과제 | 시작과 행동 | 확인할 결과 |
|---|---|---|
| **모르는 문화 발견** | 홈을 둘러보고 처음 알게 된 생활문화 하나 선택 | Korea 101의 설명과 이용 방법을 이해하고 더 알아보거나 저장 |
| **취향과 새로운 제안 비교** | 관심을 선택한 뒤 For You와 New to You 비교 | 추천 이유를 설명하고, 익숙한 관심과 새롭게 알게 된 경험을 구별 |
| **지금 주목할 문화 찾기** | Pulse에서 소개 이유와 출처 확인. 행사라면 날짜·지역·상태도 확인 | 왜 지금 소개되는지 이해하고 더 알아볼 문화나 경험 선택 |
| **SNS에서 본 경험 실행** | 샘플 사진·링크 입력 → 대상 확인 → 이용 조건 선택 | 실제 경험으로 이어지는 경로를 찾고 불가 시 대안 선택 |
| **눈앞의 내용 이해** | 메뉴·안내문 이미지 입력 → 인식 내용 확인·수정 | 번역·설명·주문 또는 대응 행동을 이해 |
| **전문 경험 바로 이용** | 홈의 인기 결과 또는 전문 메뉴로 직접 진입 | 코스·룩·학습 등의 결과를 얻고 저장·복귀 |
| **필요한 경우 결과 연결** | 저장된 Kravel 코스에 행사 추가 | 변경 이유와 전후 차이를 확인하고 선택·되돌리기 |

첫 화면은 짧게 본 뒤 ‘어떤 서비스인지’와 ‘어디서 시작할지’를 설명하게 하는 방식으로 점검한다. 대표 과제에서는 완료 여부와 함께 헤맨 지점, 잘못 이해한 정보, 도움을 요청한 시점을 기록한다. 사진 식별 정확도와 행사 최신성 같은 기술 지표는 실제 모델·데이터를 연결한 검증에서 측정한다.
