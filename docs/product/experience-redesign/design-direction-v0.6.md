# KoreaMate · 디자인 방향 및 화면 구성 브리프 v0.6

> 단계 **05 / 08 진행 중** · 디자인 검토안 · 2026-10-17  
> 기준: [서비스 경험 설계 v0.5](./service-experience-v0.5.md)  
> **아직 최종 디자인 확정 아님.** 이 문서는 이미지 시안(06단계)을 만들기 위한 제약·비교 기준이다.

## 1. 디자인 문제 재정의

이전 v0.1~v0.4의 실패는 기능 수 자체가 아니라 **사용자 경험과 시각 계층이 반대로 설계된 것**이다. 반복된 대시보드, 설명형 카드, 시나리오와 맞지 않는 장식 이미지가 개별 아이디어의 매력을 가렸다.

**디자인 목표:**
- 5초 안에 사용자가 '이곳에서 한국 문화를 발견하고 실행 도움을 받는다'고 이해할 것.
- Kravel, K-Beauty, K-Season 등의 **대표 동작을 눈으로 볼 수 있을 것**. 단순 메뉴 소개가 아니다.
- 전문 경험으로 **직접 진입**할 수 있고, AI Mate는 필요할 때 사용자가 호출할 것.
- 결합 결과(예: Kravel↔K-Season)가 **이전/이후 비교**로 확인될 것.
- 모든 화면이 **같은 브랜드**라는 인상을 주되, 모든 화면을 **같은 양식**으로 만들지 않을 것.

## 2. 세 가지 시각 방향 비교

| 콘셉트 | 장점 | 단점/위험 | 권장 적용 |
|---|---|---|---|
| **A. Culture Editorial** (여행·문화 매거진) | 탐험 설렘, 사진·콘텐츠 가치, 풍부한 문화 맥락 | 탐색 액션이 숨겨지거나 홍보 사이트처럼 보일 수 있음 | 메인 Discover, Korea Pulse, Korea 101 |
| **B. Contextual Mate** (상황 기반 도우미) | Ask/Scan/Plan B의 존재 이유와 사용 흐름이 뚜렷함 | 모든 화면이 챗봇·업무 도구처럼 보일 수 있음 | Scan, Help Me Now, 변경 근거 설명 |
| **C. Signature Studios** (각 분야 전문 체험) | 팀원별 핵심 체험이 주인공, 기능별 시각적 차별성 | 공통 브랜드가 약해지고 앱을 옮겨 다니는 느낌 위험 | Kravel, Beauty, Season, K-Class, GG |

**추천 조합(팀 결정 전 제안):** A는 *발견의 무대*, B는 *공통 동작*, C는 *깊은 체험*. 어느 하나를 전체 서비스에 강제로 적용하지 않는다.

## 3. 디자인 언어 후보 (확정 전)

| 토큰 | 후보 | 사용 목적 |
|---|---|---|
| Background | `#FAFAF7` / `#FFFFFF` | 정보가 선명한 따뜻한 중성 바탕 |
| Ink | `#152033` | 본문·제목·길찾기 정보 |
| Primary Accent | `#EC5B81` | 호출·저장·진입 CTA에 절제해 사용 |
| Support Teal | `#2E8B87` | 확인된 정보, 문화·생활 느낌 |
| Muted | `#6B7180` | 메타데이터와 보조 설명 |
| Danger | `#BE4852` | 종료·예약 불가·주의 상태 |
| Type | 한국어: Pretendard 또는 SUIT / 영문 디스플레이: 절제된 Serif 혼합 | 감성 제목과 정확한 정보 영역 분리 |

- 화려함은 **사진·문화 소재·대표 인터랙션**에서 만들고, 모든 버튼에 그라데이션을 쓰지 않는다.
- 브랜드를 통일하는 요소는 **상단 구조, 색상 체계, 도움 호출 방식, 저장·취소·출처 표시**다.
- 전문 화면까지 동일한 히어로·카드·입력 양식으로 복제하지 않는다.
- AI 이미지 속 장소·사건·가격을 **실제 검증 자료인 것처럼 보이게 사용하지 않는다**.

## 4. 첫 화면 정보 계층 (PC)

1. **경험적 영웅 영역:** '한국을 몰라도 한국을 제대로 즐길 수 있도록'라는 정체성을 사진·짧은 문구로 전달. 과도한 설명/카드 지양.
2. **즉시 행동 3개:** 묻기(Ask), 보여주기(Scan/Share), 탐색하기(Discover). 버튼이 아니라 실제 진입 가능 동작으로 설계.
3. **발견 콘텐츠:** For You + New to You(이미 좋아하는 것/새로운 것 대비), Korea Pulse(운영 날짜·출처·상태).
4. **Korea 101:** PC방·찜질방·한강라면·포토부스 등 '검색할 생각조차 못 한 문화'의 이야기.
5. **Signature Experiences:** 비대칭 편집형 레이아웃. 하나의 기획 콘셉트를 보여주는 대표 장면과 함께 각 전문 화면으로 직접 이동.
6. **My Korea:** 저장·예정·준비 필요·도움 이력. 동의한 맥락만 재사용.

**주의:** 메인에 모든 기능을 동등한 메뉴 6개로 과대 배치하는 것은 목적이 아니다. 전문 기능의 가시성은 충분히 확보하되 문화 발견 흐름을 훼손하지 않는다.

## 5. 모바일 첫 화면의 행동 우선순위

- 첫 뷰포트에 한국 문화 비주얼, 짧은 안내, **Scan 또는 Ask로 바로 진입**을 제공.
- 최근 사용자 행동이 있을 때만 My Korea 이어하기 카드 표시.
- 하단 주요 동작 후보: Discover / Scan / My Korea / Help (팀 결정 전).
- 현장에서는 터치 영역·문장 크게, 긴 설명은 접기, **필요한 다음 행동**을 먼저 노출.
- 사진·음성 입력은 허용/거절 권한 경로, 미인식·재촬영 안내, 개인정보 설명이 있어야 함.

## 6. 전문 화면별 시각적 중심

| 화면 | 메인 시각/주요 조작 | 끝까지 독립적인 가치 |
|---|---|---|
| **Kravel** | 실제 작품 맥락·촬영지 근거·크고 편집 가능한 지도/여행 동선 | 촬영지 여행 계획 생성·저장 |
| **K-Season** | 계절 변화가 보이는 비주얼 + 방문 날짜/상태 중심 행사 캘린더 | 해당 일정에 참여할 행사 찾기 |
| **K-Beauty** | 얼굴 미리보기 최우선 + 룩·색상 전환 + 전후 비교 | 한국 방문을 하지 않아도 룩/제품 구성 저장 |
| **K-Class** | 공식 영상 재생 영역 + 해설 타임라인/퀴즈 | 수준별 학습 과정 완료. Tutor는 별도 제작 공간 |
| **GG Korea** | 응원팀/경기/팬 이벤트 중심·실시간성 근거 표시 | Fan 방문 코스. Pro Path는 별도 진행 관리 |
| **Travel Food** | 메뉴 사진 위 주석·문화 설명·주문 문장 | 현장 주문과 음식 이해 |
| **History/Lifestyle** | 시대 타임라인·생활문화 스토리와 실제 체험 | 역사·문화 발견 |

## 7. 반드시 보여줘야 할 융합 장면

### 사례 A: See it → Live it → Plan B
- **입력**: SNS 공유 이미지가 화면의 주인공, 대상 확인/수정 가능
- **판단**: 운영/예약 상태와 출처·확인 시각을 시각적으로 분리
- **실패**: 왜 실행할 수 없는지 설명
- **대안**: 조건에 맞는 다음 제안 → 선택 후 일정 변경 확인
- **완결**: 사용자가 무엇을 하게 됐는지 요약, 미확인 사항 분명히

### 사례 B: Kravel ↔ K-Season
- 기존 여행(필수 촬영지) → 행사 추가 → 시간 충돌 확인
- **기존 일정 대 변경 일정**을 나란히 보이도록 설계
- 삭제되는 장소/추가되는 장소/이동·시간 영향/출처 제시
- **동의 후 적용**, 취소 시 원상복귀

### 사례 C: K-Beauty 독립 + 선택적 여행 연결
- AR 미리보기와 색상 선택이 핵심
- '한국 매장에서 확인'은 사용자가 원할 때만 열기
- 제품 재고/가격·AR 정확성·얼굴 사진 비저장 등은 검증된 것만 표시

## 8. 이미지 제작 시 금지 패턴

- 기존 다른 기능의 사진을 그냥 잘라 배경에 사용하기(장면/행사와 결과 불일치)
- 반복적인 같은 크기 카드 6개, 위젯 중심의 관리자 대시보드
- 이미지가 텍스트를 덮거나 UI 입력 자체를 사진으로 묘사해 클릭 불가능한 구조
- 모든 화면에서 동일한 유광 분홍 CTA·장식·그라데이션 반복
- 조작 전후/상태 변경의 근거 없이 'AI가 추천했어요'만 표시
- 실제 영업정보·일정·예약·이동시간처럼 보이는 임의 수치

## 9. 시안 검토 기준 (06단계 진입 조건)

1. 사용자 5초 테스트: 무엇을 할 수 있는지 설명 가능한가?
2. 대표 경험: 팀원 아이디어의 **가장 매력적인 조작**이 눈에 띄는가?
3. 브랜드: 서로 다른 화면이 KoreaMate 안의 기능임을 알 수 있는가?
4. 정보 신뢰: 출처·기간·모의 데이터가 혼동되지 않는가?
5. 연결 가치: 전문 기능을 결합했을 때 **변경 전후의 결과**가 보이는가?
6. 모바일: 첫 행동·접근성·한 손 사용이 가능한가?

## 10. 다음 산출물(06단계 전)

- 메인 정보 배치 **A/B/C 세 가지 거친 와이어프레임**을 비교.
- **Kravel / K-Beauty / Scan** 등 성격이 다른 대표 화면의 정보 우선순위를 먼저 비교.
- 팀이 선택한 방향을 기준으로 고충실도 이미지 시안 제작.
- 이미지 합의 전에 HTML 구현을 시작하지 않는다.

**검토 질문:** A(매거진)·B(상황형)·C(전문 스튜디오)를 각 영역에 차등 적용하는 원칙이 원안과 맞는지, 그리고 메인에 무엇을 가장 먼저 보여줘야 하는지 팀이 판단한다.
