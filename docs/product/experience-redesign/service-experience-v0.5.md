## B. 원래 KoreaMate에서 절대 놓치면 안 되는 문제

1. **모르니까 못한다.** 필요한 앱이나 한국만의 문화를 검색할 생각조차 못 한다.
2. **알아도 하기 어렵다.** 언어·본인인증·교통·예약·결제·현지 규칙 때문에 실행이 막힌다.
3. **정보가 흩어져 있다.** SNS→검색→지도→예약 등을 사용자가 직접 이어 붙여야 한다.

**제품 약속:** “한국을 몰라도, 한국을 제대로 즐길 수 있도록.” 사용자는 전문 에이전트 이름을 알 필요 없이 **발견하고, 이해하고, 할 수 있는 다음 행동을 선택하고, 막히면 도움을 받는다.** 그러나 전문 스튜디오에는 **바로 들어갈 수 있어야** 한다.

### 원안에서 유지할 다섯 경험

| 기능 | 왜 KoreaMate의 원안 기능인가 | 디자인·상호작용의 중심 |
|---|---|---|
| See it → Live it | SNS·영상·사진에서 본 경험을 실제 활동으로 연결 | 사진/링크 공유 → 대상 식별 → 운영·위치 확인 → 실행/대안 |
| Scan Anything | 사진 속 메뉴·안내문·제품·포스터를 번역 이상으로 이해 | 이미지 중심 카메라 UI, 인식된 영역 강조, 문화적 해설 |
| Korea Pulse | 지금 일어나는 일과 곧 종료되는 문화 발견 | 시의성 있는 편집형 콘텐츠, 날짜/출처/상태 표시 |
| For You + New to You | 좋아하는 것과 몰랐던 것을 함께 발견 | 취향 추천의 이유와 일부러 넓힌 새로운 제안 |
| Korea 101 | PC방·찜질방·한강라면·포토부스 등 검색하기 어려운 문화 소개 | 짧은 문화 스토리 → 실제 체험 정보와 이용 방법 |

**공통 서비스 역량:** AI Mate, Help Me Now(현장 도움), Travel Prepare(사전 준비), Plan B(실패 복구), My Korea(저장·일정·기억), 언어 지원과 접근성. 이는 한 화면의 하위 카드가 아니라 사용자의 어느 시점에서도 열리는 기능이다.

## C. 새 서비스 구조 — 네 개의 층으로 분리

### 1층. KoreaMate의 공통 사용자 경험

- **Discover:** Pulse / For You / New to You / Korea 101. 사용자가 먼저 탐색하거나 자연스럽게 새로운 경험을 발견.
- **Ask · Scan · Share:** 질문, 사진, 공유 링크, 텍스트/음성으로 시작. 사용자는 어떤 전문 서비스를 사용할지 몰라도 됨.
- **Help Me Now:** 현지 주문·안내문·전화 ARS·교통·예약 장벽을 해결하도록 돕는 도움 모드. 자동 처리 가능 여부는 기술 검증 필요.
- **My Korea:** 취향·저장·여행 계획·확인한 체험·사전 준비·Plan B 제안을 관리. 기억은 동의와 수정·삭제 기능이 전제.

### 2층. 문화 콘텐츠·발견을 위한 주제별 레이어

**주제는 곧 별도 서비스가 아니다.** K-Pop, Drama/Film, Food, Beauty, Seasons, Gaming, History, Lifestyle, Wellness 등은 사용자가 무엇에 관심이 있는지 나타내는 *콘텐츠 속성*이다. 여러 전문 경험이 같은 문화 객체를 참조할 수 있다.

예: 드라마 1편은 K-Class의 학습 장면, Kravel의 검증된 촬영지, Korea 101의 생활문화 설명과 연관될 수 있다. 관계에 근거가 없다면 억지로 이어 붙이지 않는다.

### 3층. 독립적인 대표 체험(전문 스튜디오)

- **Kravel:** 작품·장면 중심 여행 동선 + 장소 근거/제약
- **K-Season:** 계절별 행사·팝업·제철문화의 시기/상태 중심 캘린더
- **K-Beauty AR & Shopping:** 셀럽 룩 발견 → 메이크업 체험 → 제품 비교·묶음
- **K-Class Learner:** 콘텐츠 장면 기반 수준별 한국어 학습·문법·퀴즈
- **GG Korea Fan:** 팀/선수 중심 경기·팬 이벤트·굿즈·팬 방문 코스
- **Travel Food Experience:** 음식·메뉴 이해·현지 맛집 문화와 주문 도움(여행자용 아이디어)
- **확장 전문 경험:** 게임 배경지, 역사 시대별 여행, 계절 문화·생활 체험 등은 고유한 표현(지도·시대 타임라인·체험 설명)을 선택할 수 있음.

**직접 진입 보장:** 각 전문 기능은 KoreaMate의 Scan을 경유해야만 열리는 구조가 아니라 탐색 페이지와 딥링크로 곧바로 접근할 수 있다.

### 4층. 다른 목표 사용자의 별도 전문 모드 / 생태계 후보

- **K-Class Tutor:** 한국어 교사의 학습 목표→클립 선택→수업안·워크시트 생성.
- **GG Korea Pro Path:** 종목·수준·자격 조건을 기준으로 대회와 연습 준비.
- **K-Food Market Curator:** 한국 식품기업의 제품/국가별 수출시장·경쟁상품 분석(B2B). 여행자용 K-Food와 **분명히 다른 제품**.
- **Medical & Wellness:** 의료·시술·건강검진은 K-Beauty의 화장품/AR과 구분. 정확성·법률·자격·개인정보 검증이 필요하며 단순 여행 추천과 동등하게 취급하지 않음.

이들은 **범위에서 제거된 것이 아니다.** 공통 브랜드/기술의 재사용 가능성은 열어 두되, 현재 여행자용 메인 경험에 끼워 넣을 필연성은 별도로 검증한다.

## E. 대표 경험(Signature Experience) 정의

**공통 작성 규칙:** ①왜 들어오는가 ②한 번의 핵심 조작 ③대표 결과 ④직접 계속 사용할 이유 ⑤필요한 경우만 연결 ⑥실제 검증 조건. 모든 전문 화면을 같은 카드/입력 양식으로 만들어서는 안 됨.

| 전문 경험 | 사용자의 시작 의도 | 화면에서 가장 돋보여야 할 장면 | 독립 체험의 종료 상태 | KoreaMate에서 추가할 수 있는 가치 |
|---|---|---|---|---|
| Kravel | 좋아하는 드라마 장소를 방문하고 싶다 | **장면→촬영지→동선**으로 변하는 큰 지도·일정 | 근거 있는 촬영지 여행 코스 저장 | K-Season을 반영해 코스 재계산·Plan B |
| K-Season | 특정 계절·날짜에 무엇이 열리는지 알고 싶다 | **시즌 전환+날짜 캘린더+행사 사진** | 가능한 행사와 방문 조건 저장 | 원래 여행 코스의 충돌·이동 제약 확인 |
| K-Beauty | 좋아하는 룩을 직접 적용해 보고 싶다 | **가장 큰 얼굴 미리보기+룩 전후 비교** | 룩·제품 후보를 저장(여행 없이도 유효) | 방문 의사가 있을 때만 매장·여행 연결 |
| K-Class Learner | 좋아하는 콘텐츠로 한국어를 배우고 싶다 | **영상 플레이어+대사/문법 타임라인+퀴즈** | 수준별 학습 결과·복습 기록 | 원하면 장면 관련 문화/촬영지 탐험 연결 |
| K-Class Tutor | 수업 준비 시간을 줄이고 싶다 | **학습 목표→수업안 생성→편집/내보내기** | 튜터가 검토 가능한 수업안 | 학습 자료의 K-Culture 근거 보강 가능 |
| GG Korea Fan | 팬으로서 한국 방문을 즐기고 싶다 | **응원 팀 중심 경기·팝업·팬 지도** | 방문 가능한 팬 경험 코스 | K-Season/일정 결합, 종료 이벤트 대안 |
| GG Korea Pro | 대회 참가와 준비를 관리하고 싶다 | **자격/마감/종목별 훈련 계획** | 참가 후보 및 준비 계획 | 방한 대회라면 이동·문화 경험 보조 가능 |
| 여행자용 Food | 한국 메뉴와 음식문화를 알고 싶다 | **메뉴 사진 주석·매운맛·주문 문장** | 이해·선택·주문 보조 | 주변 체험, 언어 지원, Korea 101 연결 |
| K-Food Market | 해외 진출 기회를 조사하고 싶다 | **제품-국가-경쟁상품 비교 대시보드** | 근거가 있는 시장 분석 결과 | 여행자 앱과 별도 B2B 경험으로 보존 |
| History/Lifestyle | 몰랐던 한국을 탐험하고 싶다 | **시대 타임라인·생활문화 스토리·장소** | 해보고 싶은 경험·방문 후보 저장 | 여행 조건에 맞는 실행 경로·도움 연결 |

**시각 설계 의도:** Kravel=시네마틱 여행 지도 / K-Season=살아 있는 계절·캘린더 / K-Beauty=몰입형 스튜디오 / K-Class=영상 학습 환경 / GG=팬의 에너지와 일정 / Food=사진 기반 안내 / History=타임라인. **공유할 것은 기능의 배치가 아니라 브랜드와 공통 동작**이다.

## F. 융합은 세 가지 방식으로 구분해 구현한다

1. **결과 개선형(강한 융합):** Kravel ↔ K-Season. 행사 정보로 시간 충돌과 이동을 다시 계산, 변경 전후 비교 후 승인. 혹은 GG Fan의 행사/경기 일정을 여행 플래너가 현실 조건과 맞춰 수정.
2. **진입/실행형(연결형):** SNS → See it → K-Beauty 룩 → AR 체험 → 사용자가 원할 경우 한국 매장 후보 탐색. **AR만으로 완결된 가치**가 있어야 함.
3. **맥락·지식 보강형:** 메뉴 Scan → 음식 문화·주문법·STT/TTS → 필요 시 K-Class 학습; 콘텐츠 → 생활문화 Korea101. 사용자가 학습이나 여행을 원하지 않으면 강제하지 않음.

**강제 연결 금지 조건:** 대상 사용자가 다름 / 현재 목적 달성에 도움이 안 됨 / 관계 근거가 없음 / 데이터가 충분하지 않음 / 입력 정보 제공에 동의하지 않음.

### 대표 시나리오 1 — See it → Live it → Plan B

1. SNS 사진/링크 입력 → 입력 이미지에서 후보 식별(신뢰도/불확실성 표기).
2. 대상이 무엇인지 설명. K-Season의 *확인 가능한 최신 행사 정보* 조회.
3. 이미 종료되었거나 본인인증/예약 조건 때문에 불가하면 **이유와 출처** 표시.
4. 목적을 지키는 대안 2~3개 제안. 새로운 장소는 지역·시간·취향 조건을 반영.
5. 사용자가 선택하면 **기존 일정과 비교→수정 내용 승인→My Korea 반영**.
6. 필요하면 언어/교통/예약 안내 제공.

> 단순한 종료 안내나 추천 카드가 아니라, **포기하지 않아도 되도록 실제 계획이 수정되는 것**이 핵심.

### 대표 시나리오 2 — Kravel ↔ K-Season

1. Kravel에서 작품/필수 장소/여행일/이동 방법 입력 → 초안 코스 생성.
2. K-Season에서 그 날짜에 방문 가능한 행사를 발견.
3. 행사 시간과 기존 방문 순서가 충돌하면 **그 근거를 확인**.
4. 여행 플래너가 원래의 필수 장소 보존/이동시간 제약을 우선으로 **수정 코스를 생성**.
5. **변경 전후 지도·시간표·포기하는 항목** 비교 → 사용자 승인 또는 되돌리기.

> 행사 추가 결과로 **Kravel의 결과물이 달라져야** 협력의 의미가 있다. 단순 날짜 전달은 충분하지 않음.

### 대표 시나리오 3 — K-Beauty의 독립성과 선택적 연결

1. 뷰티 룩/제품 사진에서 시작하거나 K-Beauty 전문 스튜디오에 직접 진입.
2. 색상·룩 변경, 전후 비교, 제품 세트를 확인. **이 상태로도 완결된 경험**.
3. 원하면 한국 매장 후보 확인, 방문 계획에 저장. 한국에 갈 계획이 없다면 룩을 저장하고 종료.
4. 재고·가격·AR 품질·사진 처리 조건은 별도 근거 검증 후 기능 수준 구분.

### G2. PC 메인 화면의 정보 우선순위(제안)

**첫 화면(first viewport)**

- **상단:** KoreaMate 로고 / Discover / Experiences / My Korea / 언어·계정. AI Mate는 어디에서든 접근 가능.
- **주인공:** 한국 문화를 발견하게 만드는 장면(영상/사진)과 한 문장. 단순한 거대한 입력창이나 기능 목록으로 만들지 않음.
- **첫 행동:** `묻기`, `찍기/공유`, `새로운 경험 탐색` 중 하나가 즉시 보이고 조작 가능.
- **현재 맥락:** 방한 전 사용자에게는 준비·일정, 여행 중 사용자에게는 현재 위치/시간 기반 선택적 도움. 위치 미동의라면 강요하지 않음.

**스크롤 아래(유동적 편집 레이아웃)**

1. `For You + New to You`: 개인 취향에 맞는 것과 몰랐던 것의 대비.
2. `Korea Pulse`: 행사·팝업·트렌드, 업데이트/운영 상태 표시.
3. `Korea 101`: PC방·찜질방·한강라면 등 짧은 문화 이야기와 해보기.
4. `Signature Experiences`: 6개 동등 크기 타일이 아니라 **대표 체험을 보여주는 비대칭 편집형 모자이크**. 각 스튜디오에 바로 진입.
5. `My Korea`: 저장한 코스·다가오는 일정·확인이 필요한 문제를 연속적으로 이어주는 모듈.

**공통 오버레이:** 사용자 호출형 AI Mate/Help Me Now. 전문 화면에서도 열 수 있지만 모든 클릭마다 등장하지 않음.

### G3. 모바일 메인 구조(제안)

- 상단은 감성적인 장면 일부 + 짧은 한 문장 + `Scan` 즉시 실행.
- 하단 내비게이션은 **Discover / Scan / My Korea / Help** 위주. 각 분야 전문 스튜디오로 이동하는 `Explore` 목록은 Discover 내에서도 접근.
- 카메라/음성 등 현장에서 자주 쓰는 기능을 큰 터치 영역으로 배치.
- 행사/긴급 도움의 운영 정보와 출처는 접지 않고 확인 가능하게 제공.
- 모든 화면의 긴 설명은 필요할 때 펼치되, **다음 행동**을 우선 표시.

### G4. 전문 화면의 디자인 공통 요소와 다른 요소

**공통으로 유지:** KoreaMate 정체성(로고/상단), 언어 선택, 도움 호출, 저장/일정 공유, 정보 출처·미확인 표시, 사용자 동의/취소/되돌리기.

**공통으로 만들지 않을 것:** 크기가 같은 영웅 배너, 동일한 2열 카드, 동일한 입력 상자/버튼 위치, 모든 곳에서 같은 핑크색 강조. 각 경험의 본질에 맞는 공간 구성을 허용.

## H. 디자인 방향 후보: 축소가 아니라 표현의 질을 높이기

| 방향 | 설명 | 장점 | 유의점 |
|---|---|---|---|
| A. K-Culture 매거진 | 사진·에디토리얼 타이포·문화 이야기 중심 | 발견의 설렘과 풍부한 세계관 | 직접 조작할 기능이 장식에 묻힐 수 있음 |
| B. Korea Culture Atlas | 도시·테마·시간을 가로지르는 탐험 지도 | 여러 분야를 자연스럽게 연결 | 지도 중심이면 Beauty·K-Class 경험 표현이 제한될 수 있음 |
| C. AI Travel Companion | 개인적이고 친근한 대화/카메라/도움 중심 | KoreaMate의 원안 문제 해결을 잘 드러냄 | 대화창만 남으면 문화 탐색이 약해짐 |

**권고 초안:** A의 이미지·발견 매력 + B의 테마 연결 감각 + C의 맥락/도움 기능을 결합. 단, *실제 홈의 구성*을 세 가지 요소로 등분하지 않고 하나의 연속된 사용자 경험으로 편집.

**색상·타이포 제안:** 낮은 채도의 따뜻한 배경과 깊은 잉크색 텍스트를 기본으로, KoreaMate 행동 버튼에 일관된 강조색을 사용. Kravel의 시네마틱 계절감, Beauty의 화장품 질감, GG의 에너지, History의 아카이브 감성은 개별 스튜디오에서 변주. 실제 팔레트·서체는 다음 단계에서 여러 시안을 비교해 확정.

**이미지 제작 지침:** 서로 다른 콘텐츠와 행동의 정확한 일치(팝업 포스터 ≠ 벚꽃 축제 사진), 저작권·초상/상표 권리 확인, 이미지에 가짜 운영 날짜·예약 완료 UI를 사실처럼 넣지 않기. 이미지 하나를 여러 도메인에 억지로 재사용하지 않기.

## I. 팀 병렬 작업을 위한 최소 데이터·행동 계약(초안)

| 객체 | 공유해야 할 필드 | 구현 및 화면에서 반드시 구분할 상태 |
|---|---|---|
| UserContext | 언어, 취향, 방문 날짜, 위치(동의시), 이동·예산·음식 제약 | 미설정·동의·해제·오래된 정보 |
| CultureObject | 콘텐츠 ID, 종류, 제목, 관련 작품/주제, 언어, 참조 관계 | 확인된 관계 vs 추정 관계 |
| PlaceOrEvent | 장소 ID, 좌표, 행사 기간, 운영 조건, 출처, 조회 시간 | 운영 확인·미확인·종료·예약 필요 |
| SpecialtyResult | 전문 기능별 결과 ID, 내용, 편집 가능 항목, 생성 근거 | 초안·확인·저장·취소 |
| PlanChange | 원본 일정, 제안된 변경, 충돌 이유, 영향 받는 방문지 | 제안·승인·되돌림 |
| ExternalAction | 지도/예약/결제 링크, 지원 범위, 실행 결과 | '안내'와 '완료'는 다름 |

**연결 계약:** 전문 기능은 `userGoal + constraints + verifiedContent`를 받아 독립 결과를 반환할 수 있다. KoreaMate는 그 결과를 연결 제안으로 보여주되, 임의로 확정·결제·예약하지 않는다. 모든 전문 서비스를 각각 '에이전트'로 만드는 것은 필수가 아니며 데이터 조회/규칙으로 가능한 작업은 더 간단한 수단이 적합할 수 있다.

## K. 결정 상태와 미확정 항목

- 확정된 팀 개발 범위, 담당자, 스튜디오별 우선순위는 **아직 확인된 사실이 아님**.
- 본 문서의 모든 깊이·화면 배치는 **비교 가능한 초안**이며, 사용자 또는 팀의 최종 선택을 대신하지 않음.
- 기술적으로 구현 가능한 것과 기획/디자인에서 표현 가능한 것은 구분. 실제 AI·외부 예약/지도/AR/음성/ARS API를 연결한 것처럼 시연하지 않음.
