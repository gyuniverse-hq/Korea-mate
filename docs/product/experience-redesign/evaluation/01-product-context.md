# 01 · 제품 문제·사용자·기획 정체성

> **설계 가설**을 정리한 문서다. 외국인 사용자 조사를 완료했다는 뜻은 아니다.

## 1. 해결하려는 세 가지 불편

1. **모르니까 못 한다.** 여행자가 어떤 앱이나 서비스를 준비할지, 어떤 한국 문화가 존재하는지 검색할 생각조차 못한다.
2. **알아도 하기 어렵다.** 언어, 예매·본인 인증, 주문, 교통, 현지 규칙 때문에 관심이 실제 행동으로 이어지지 못한다.
3. **연결 비용이 크다.** SNS → 검색 → 번역 → 지도 → 일정/예약을 여행자가 직접 여러 앱에서 이어 붙여야 한다.

### 핵심 대상 사용자(첫 검증 가설)

- 한국 여행을 준비 중이거나 현지에 머무는 **외국인 자유여행객**. 첫 방문자가 우선 가설이며, K-Culture 팬·재방문 여행객도 포함 가능.
- 전형적 상황: SNS에서 본 한국 팝업이 무엇인지 궁금함 / 한국어 키오스크 사용 어려움 / 내가 좋아하는 드라마 촬영지에 가고 싶음 / 방문 중 이벤트가 종료되어 다시 계획해야 함.
- **별도 사용자군**: K-Class Tutor(한국어 튜터), GG Korea Pro Path(프로 지망 게이머), K-Food Market Curator(기업 B2B). 모두 여행자 사용자 여정에 의무적으로 넣지 않는다.

## 2. KoreaMate 원래의 핵심 기능

| 원안 | 사용자에게 일어나는 일 | 화면상 대표 행동 |
|---|---|---|
| See it → Live it | SNS/이미지 속 경험을 실제 방문으로 바꿈 | 공유 → 대상 확인 → 방문 조건 → 다음 행동 |
| Scan Anything | 메뉴·포스터·상품·안내문을 단순 번역 이상의 문화·이용 맥락으로 이해 | 촬영/업로드 → 확인/설명 |
| Korea Pulse | 지금 인기 있는 문화·행사를 발견 | 주목할 만한 콘텐츠와 시기/출처 확인 |
| For You / New to You | 취향에 맞는 것과 몰랐던 문화를 균형 있게 발견 | 추천 이유 → 저장·탐색 |
| Korea 101 | PC방·찜질방·포토부스·한강라면 등 생소한 생활문화 소개 | 짧은 이야기 → 실제 이용 안내 |
| Help Me Now / Plan B | 준비, 현장 문제, 운영 종료·예약 실패에서 다음 행동 제안 | 문제 제시 → 근거 → 대안 → 승인 |
| My Korea | 명시적으로 선택·저장한 일정과 취향을 다음 단계에서 활용 | 저장, 수정, 삭제, 필요 시 연결 |

**제품 정체성:** 여러 서비스를 모은 런처나 범용 챗봇이 아니라, 사용자에게 필요한 문화·도구를 **상황에 맞게 이해·연결해서 실제 행동을 돕는 동반자**.

## 3. 전문 기능: 묻히지 않아야 할 핵심 가치

| 기능 | 반드시 유지할 독립적인 대표 경험 | 자연스럽게 결합될 때 |
|---|---|---|
| Kravel | 좋아하는 K-드라마·영화 → 근거 있는 촬영지 → 이동 조건을 반영한 여행 코스 | K-Season 일정 정보를 받아 코스 충돌 재조정 |
| K-Season | 계절/날짜/지역별 축제·팝업·공연 탐색과 행사 캘린더 | 다른 여행 코스의 방문 가능 시간 검증 |
| K-Beauty AR | 셀럽 룩 선택 → 얼굴/메이크업 미리보기 → 제품 구성 확인 | 원할 때만 한국 매장·여행 일정으로 연결 |
| GG Korea Fan | 응원 팀과 방한 일정에 맞는 경기·팬 이벤트·굿즈 코스 | 경기/팝업 정보가 여행 계획에 반영됨 |
| K-Class Learner | 공식 K-콘텐츠 클립과 수준별 해설·퀴즈 | 관련 작품·장소 탐색에 선택적 연결 |
| K-Food / 생활문화 | 메뉴·음식·현지 이용법을 사진과 문화 맥락으로 설명 | 현장 도움·관심사 기반 다음 체험 |

다른 사용자층의 Tutor/Pro Path/B2B 분석은 전문 기능의 정체성을 유지하면서 선택적 기술 공유만 검토한다. 식품기업을 위한 수출시장 분석을 여행자용 음식 추천으로 바꾸지 않는다.

## 4. 핵심 융합 시나리오와 성공 판정

**A. 사진/SNS → See it → Live it → Plan B**
- SNS 속 팝업을 식별·확인 → 종료된 행사라면 이유와 출처 제시 → 사용자 제약을 만족하는 대안 → 사용자 선택을 일정에 반영.
- 단순히 행사 소개 페이지로 이동시켰다면 '융합 완료'로 보지 않는다.

**B. Kravel → K-Season → Kravel**
- 촬영지 여행 코스 작성 → 같은 날짜의 행사 발견 → 시간 충돌 판정 → 필수 장소와 행사 제약을 고려한 수정 코스 비교 → 승인 후 반영.
- 날짜를 전달하거나 링크만 열어서는 실제 사용자 결과가 개선되지 않는다.

**C. K-Beauty 독립 체험 + 선택적 연결**
- 메이크업 룩 비교 자체로 경험이 끝나도 괜찮다 → 필요할 때만 쇼핑·방문 제안을 한다.
- 모든 화면에서 AI Mate나 여행 계획을 강제하면 오히려 독립 서비스의 가치를 훼손한다.

## 5. 이번 메인 디자인에 기대하는 사용자 이해

첫 방문자가 **5초 안에** 아래 두 가지를 동시에 짐작해야 한다.
1. 한국에서 지금 즐길 거리와 몰랐던 문화를 발견할 수 있다.
2. 궁금한 사진·SNS·질문을 보여주면 한국 여행의 다음 행동까지 도움받을 수 있다.

그리고 **직접 전문 기능을 찾는 사용자**는 Kravel, Beauty, Season으로 바로 들어갈 수 있어야 한다. 이것이 메인 경험과 전문 경험을 동시에 살리는 설계 조건이다.
