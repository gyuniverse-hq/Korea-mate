# 03 · v0.9 디자인 의도·실제 화면 비교·우려 사항

> **평가 자료, 평가 결론 아님.** 아래는 제작 과정에서 발견한 문제 후보이며 외부 평가자가 반드시 동의할 필요는 없다. 실제 이미지를 보고 독립적으로 판단해 주세요.

## 1. 어떤 디자인을 이어받았나

이전 v0.1~v0.4의 주요 문제는 사진/문화 경험보다 대시보드·카드·설명이 앞서는 것, 서로 다른 전문 기능을 동일 템플릿에 넣는 것, 구현 과정에서 이미지 디자인의 정체성을 잃는 것이었다.

v0.7에서는 **무엇을 우선 노출하는가**에 따라 A(문화 발견)·B(상황 해결)·C(전문 체험) IA를 비교했고, v0.8에서는 D라는 혼합 IA 위에 네 개의 시각적 정체성을 실험했다. 그러나 v0.8의 평면 그래픽은 초기 D 고충실도 이미지의 풍부한 문화 사진과 조형을 재현하지 못해 **현재 채택 후보에서 제외**했다.

v0.9는 **메인 한 화면만** 고충실도 이미지 기준으로 다시 설계한 후 HTML로 재현하는 실험이다.

## 3. 의도적으로 유지한 요소

- **실제처럼 몰입감 있는 문화 사진**을 중심으로 브랜드의 첫인상을 만든다.
- **Hero의 검색·카메라·음성**은 별도 페이지로 이동하지 않아도 노출되는 주요 입력 경로다.
- 사진 위 어두운 영역 + 아래 밝은 콘텐츠 영역으로 역할을 분리한다.
- 추천 콘텐츠는 생활문화·음식·뷰티·행사 등 서로 다른 문화 소재가 공존하게 한다.
- 전문 경험은 메인의 하위 메뉴 하나로 억지 축소하지 않고, 각자 다른 목적을 보여주는 이미지와 진입 문구를 가진다.
- 카드 클릭/추천 저장 등의 시연은 실제 UI 요소로 조립되어 있으며 **화면 전체를 이미지 한 장으로 붙인 것은 아니다**.

## 5. 시안과 HTML 사이에 제작자가 알고 있는 차이

- AI 생성 시안의 손글씨·장식적 타이포를 HTML에서 그대로 재현하지 않았고, 읽을 수 있는 실제 텍스트로 대체했다.
- 사진 자산은 원 시안에서 분리해 새 비율에 맞게 배치했다. 일부 카드의 선명도·크롭이 목표보다 부족하다.
- 우측 패널과 콘텐츠 영역의 비율·여백은 실제 반응형 UI로 구현하면서 변화했다.
- 기본 카드/버튼은 실제 HTML이며, 임시 모달과 저장·필터가 동작한다. 실제 서비스 결과를 생성하지는 않는다.
- **'2025 봄', 현재 운영, 예약 가능 같은 문구는 실제 최신 자료를 검증한 사실이 아니다.** UI 평가에서 이를 신뢰성/표시 규칙 문제로 다룰 것.

## 6. 다음 디자이너에게 필요한 판단

**외부 평가자는 제작자의 선호에 얽매이지 않아도 된다.** 기존 톤을 유지하되 개선할 수 있는지, 방향을 크게 바꾸는 것이 맞는지 모두 고려해 달라. 다만 최초 시안의 강점인 몰입감과 문화 발견의 설렘은 우연히 사라지지 않게 검토해 달라.

피드백은 '좋다/예쁘다'가 아니라 **화면 구역, 어떤 이용자에게 어떤 문제가 생기는지, 어떻게 바꾸면 좋을지**로 작성하고, PC와 모바일을 분리해 우선순위를 제안해 달라.
