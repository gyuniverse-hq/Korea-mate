# KoreaMate · 실제 융합 시나리오 도출 및 화면 역설계 v0.3

- **작성 목적:** 한국 문화 발견에서 실제 경험·문제 해결까지, 팀원 기능 간 실질적인 증분 가치를 검증하고 화면 설계의 출발점 마련
- **상태:** 개인 기획 검토안 / 팀원 아이디어의 통합·범위·담당은 아직 확정 아님
- **자료 시점:** 2026-10-17, KoreaMate v0.2 문서 및 2026-10-13~16 Discord 제안 참고
- **주의:** 모든 시나리오는 사용자 검증 전의 가설이며, 실시간 운영상태·AR·예약·추천 성능을 구현했다고 주장하지 않음

## 1. 설계 원칙과 원안 보존

**원안 문제:** (1) 무엇을 준비하고 즐겨야 하는지 몰라 못 한다. (2) 언어·인증·예약·이동으로 알아도 실행하지 못한다. (3) 정보와 서비스가 분산되어 발견→행동 전환에 비용이 든다.

**원안 핵심 경험 5개:**
1. See it → Live it: SNS/콘텐츠에서 실제 경험으로
2. Scan Anything: 메뉴·안내문·제품·포스터 의미와 사용 방법
3. Korea Pulse: 지금 인기·예정·곧 종료되는 경험
4. For You: 선택한 취향·여행 조건에 맞춘 설명 가능한 추천
5. Korea 101: 검색조차 하지 못할 수 있는 한국 문화의 선제 발견

**원안 전반의 역량:** Travel Prepare, Help Me Now, Plan B, My Trip/My Korea Memory, New to You, Korea Quest(선택 확장).

**진짜 융합의 조건:** 두 기능이 정보를 주고받았다는 사실이 아니라, 두 기능의 검증된 정보·규칙·체험 결과가 결합되어 **더 나은 최종 판단/수정/행동**이 발생해야 함. A→B→A로 돌아와 A의 결과가 바뀌었는지 확인. 사용자에게는 왜 바뀌었고 어떤 정보가 확정·미확정인지 설명해야 함.

**제품 경계:** KoreaMate = 외국인의 한국 문화 발견과 실행·도움. 팀원별 전문 기능은 직접 진입과 깊이 있는 독립 체험 유지. 반드시 KoreaMate AI Mate를 거쳐야만 이용할 수 있도록 만들지 않음.

각 항목 1~5점의 기획적 추정. 사용성 실험이나 시장 검증 수치 아님. 점수 = Σ(항목 점수 ÷ 5 × 가중치).

- **증분 사용자 가치** 30점: 둘 중 하나만으로는 어려운 결과를 결합으로 더 잘 얻는가

- **사용자가 시연에서 이해하기 쉬움** 15점
- **팀원 고유 체험 독립성 보존** 15점

## 4. 실제 융합 시나리오 설계

### S01. SNS에서 본 팝업 → 방문 불가 → 검증된 대안·재계획
- **사용자:** 서울 여행 중인 외국인이 친구가 공유한 SNS 팝업 스크린샷을 업로드.
- **원안 기여:** See it → Live it이 이미지에서 후보를 찾고, Scan Anything이 포스터를 읽고, Help Me Now/Plan B가 해결책을 지원.
- **전문 기여:** K-Season은 공식 행사명·기간·예약/운영 조건과 유사 행사 후보를 제공. Kravel/일정 기능은 원래 방문 계획·이동 제약을 검토해 선택한 대안을 코스에 반영.
- **새로운 결과:** 방문 불가 이유와 확인 시각을 보여주고, 기회가 남은 대안을 비교. 사용자의 승인 이후 기존 일정을 수정하고 이전/이후 일정 차이를 제시.
- **없애기 실험:** K-Season 없이 → 최신 운영 정보를 알기 어렵고, Kravel 없이 → 기존 일정과 대안의 이동 가능성을 결합하기 어렵다.
- **화면:** 발견 결과 상세(식별 후보/확인 상태) → 행사 깊이 보기 → '다른 경험 찾기' → 변경 비교 → 일정 반영.
- **검증:** 정답 장소 식별률, 종료 오인 안내율, 대안 적합성, 일정 변경 성공률, 출처/갱신 시각 인지율.

### S02. 이미 만든 Kravel 여행 → K-Season 행사 발견 → 일정 충돌 해소
- **사용자:** 드라마 촬영지 투어를 완성한 여행자가 같은 날 열리는 야간 축제를 발견.
- **전문 기여:** Kravel이 장소·이동 수단·필수 방문지를 유지하고, K-Season이 행사 기간·운영시간·위치·입장 조건을 제공.
- **새로운 결과:** 단순 일정 합치기가 아니라 중복 시간과 이동 부담을 표시하고, 최적화된 방문 순서를 재생성. 원래 코스와 수정 코스를 나란히 제시.
- **없애기 실험:** 행사 정보가 없으면 맞춤 방문 기회를 놓치고, 동선 엔진이 없으면 단순 목록 추가 이상이 되기 어려움.
- **화면:** Kravel 코스 상세 → 추천 행사 표시 → '일정에 반영' → 변경 전/후 지도·시간표 → 적용/되돌리기.
- **검증:** 충돌 탐지 정확도, 제약 충족, 사용자 수용률, 이동시간 변화, 잘못된 예약 가능성 표현률.

### S03. SNS 셀럽 메이크업 → K-Beauty AR → 한국 매장 방문
- **사용자:** 본인이 좋아하는 메이크업을 영상/사진에서 발견, 한국 방문 중 비슷한 룩을 체험하고 구매하고 싶다.
- **원안 기여:** See it/Scan이 룩/제품의 후보를 식별하며 사용자에게 확인 요청. For You가 피부/취향에 맞춘 추천을 제공하되 추측 표기.
- **전문 기여:** K-Beauty AR은 립/블러셔 등 직접 시도할 수 있는 체험과 Look-to-Cart를 제공. 여행 일정 모듈은 사용자가 고른 매장·방문 날짜를 기존 코스에 연결.
- **새로운 결과:** 직접 체험한 룩을 실제 방문/구매 후보로 전환. 매장 재고 확인 전에는 '판매/픽업 가능' 단정 금지.
- **화면:** 룩 발견 → K-Beauty 전문 AR → 제품 세트 → 매장 찾기 → 내 여행에 저장.
- **검증:** 룩-제품 매칭 근거, 전후 비교 유용성, 실제 재고 근거와 구분, 필요한 선택 단계 수.

### S04. GG Korea 해외 팬 → 경기·팝업 → 실행 가능한 팬 하루 코스
- **사용자:** 응원팀이 있는 해외 팬이 방한일을 정하고 경기와 행사에 참가하고 싶다.
- **전문 기여:** GG Korea Fan이 경기 일정/팬덤 정보·굿즈·행사 후보를 담당. K-Season은 팝업 기간과 상태를 확인. Kravel의 동선 기능이 지역·시간·이동 수단 기준 방문 순서를 검토.
- **새로운 결과:** 실제 참석 가능한 경기가 있는 날을 기준으로 팬 이벤트+주변 문화 방문 계획을 제안하고 예매 불가/종료 시 대안을 제시.
- **주의:** GG Korea Pro Path는 팬 트랙과 다른 이용자/결과이므로 접점이 있을 때만 여행 지원.

### S05. 드라마 클립으로 한국어 학습 → 촬영지 여행
- **사용자:** 한국어 학습자가 공식 드라마 클립을 공부하다 작품의 장소에 관심을 가짐.
- **전문 기여:** K-Class Learner는 수준별 장면/해설/퀴즈를 제공. Kravel은 작품과 촬영지의 출처 연결과 이동 코스를 제공. Korea 101은 장면의 생활문화 배경을 설명.
- **새로운 결과:** 단순 '작품 연관 상품 추천'이 아니라 학습한 장면/표현을 실제 장소/문화 배경과 연결한 탐색. 여행 의사가 없는 학습자는 학습만 계속 가능.
- **제약:** 공식 영상 임베드의 권한, 자막·대사 저장/분석 권리, 특정 장면-촬영지 관계 검증. 학습 결과를 여행이라는 목적에 무리하게 종속하지 않음.

### S06. 식당 메뉴/키오스크 Scan → 이해·주문·원하는 경우 깊이 학습
- **사용자:** 한국 음식 메뉴가 낯설고 어떻게 주문할지 모름.
- **원안 기여:** Scan Anything + Help Me Now가 메뉴 의미·알레르기 주의·키오스크 단계와 직원에게 보여줄 문장을 지원. Korea 101이 주문문화, 반찬/매운맛 등 맥락 제공.
- **전문 연결:** 음식 체험 안내로 이어질 수 있음. K-Class Learner에 사용자가 원할 때 '이 표현을 제대로 배우기'로 이동해 수준별 퀴즈/학습을 시작할 수 있음.
- **주의:** K-Class를 단순 번역기로 축소하지 않음. 알레르기나 원재료는 이미지 추정만으로 확정 금지. '음식 도움'은 B2B K-Food Market의 기능으로 표시 금지.

### S07. 인기 외에 몰랐던 한국 문화 → 계획/경험 → 다음 큐레이션
- **사용자:** K-Beauty 관심은 명확하지만 한국의 포토부스/한강라면/찜질방 문화를 전혀 모름.
- **원안 기여:** For You는 취향에 맞춘 발견, New to You/Korea 101은 미경험 콘텐츠, Korea Pulse는 지역·시점에 맞는 정보를 제안.
- **새로운 결과:** 익숙한 취향만 반복 노출하지 않고 방문 가능한 새로운 경험도 소개; 사용자가 실제로 선택한 경험을 다음 추천에 반영.
- **주의:** 이용자 동의 없는 위치/행동 추적 불가. 인기도·추천 이유·미경험 가설은 구분. 여행자 경험용 K-Food와 연결 가능.

### S08~S10. 연결 가능하지만 핵심 융합을 강제하지 않을 경우
- **GG Korea Pro Path:** 대회 참가·자격·연습계획이 주 기능. 한국 방문 대회라면 여행/현지 도움만 선택적으로 연결. 독립적인 프로 대회 기능 자체가 살아야 함.
- **K-Class Tutor:** 학습자 수준·수업 목표·클립 해설과 수업자료가 주요 결과. 관광 경험은 수업 소재 후보 정도로 활용할 수 있지만, 사용자는 튜터이므로 핵심 사용자 여정 분리.
- **K-Food Market Curator:** 국가별 무역 통계·유사 해외상품 분석을 여행자 추천에 변환하는 것은 목적을 훼손할 가능성. 별도 B2B 서비스 유지, 데이터 검증·검색 모듈의 **기술·연구 노하우**만 공유하는 경로가 현실적. 추후 별도 기업용 플랫폼군/파트너 서비스 확장 가설은 열어둠.

## 5. 화면 설계 결과 — 메인부터 역설계

### 5.1 메인 화면: KoreaMate 정체성을 전면에

1. **Hero / 도움 진입:** '한국에서 무엇을 해보고 싶나요?' Ask, 사진/SNS 업로드, 여행 준비, Help Me Now 바로가기. 여행 전·여행 중 개인 상황에 따라 순서를 바꿀 수 있음.
2. **For You + New to You:** 선택한 관심사와 여행 지역·날짜를 바탕으로 잘 맞는 경험뿐 아니라 *몰랐던 문화* 소개. 추천 이유/근거 제공.
3. **Korea Pulse:** 지금 참여 가능한 행사, 제철 경험, 종료 임박 콘텐츠(최신성 검증/미확인 구분).
4. **Signature Experiences:** Kravel, K-Beauty, K-Season, K-Class Learner, GG Fan 등 독립 체험에 바로 들어갈 수 있는 사진 중심 영역. 같은 카드 틀이어도 별도 체험 화면은 고유 UI 유지. Pro/Tutor/B2B는 사용자군별 전문 서비스 진입으로 안내.
5. **My Korea Plan / Next Step:** 저장한 것에서 실제 다음 행동(방문 가능 여부, 제약, 일정 충돌, 필요한 준비)을 보여줌. '저장함'만 나열하지 않음.
6. **항시 접근 가능한 AI Mate / Help Me Now:** 버튼이 어느 화면에서도 열리되, 전문 기능 사용을 방해하지 않음.

### 5.2 반드시 새로 만들어야 하는 공통 화면 세 가지

**A. 콘텐츠 이해 화면(Discover Detail):** 입력 SNS/사진/검색 결과 → 후보 식별 → 근거/날짜/확실성 → '이게 무엇인지' 해설 → '할 수 있는 행동' → 전문 기능별 깊은 체험으로 진입. 모든 콘텐츠를 억지로 모든 기능에 연결하지 않음.

**B. 경험 결합 화면(Experience Composer):** 전문 기능의 결과를 일정이나 컬렉션에 추가할 때 기존 날짜/장소/취향과 충돌을 검사. 새 결과의 이점·손실·불확실성을 요약하고 사용자 승인을 받아 변경 적용. **융합을 눈으로 증명하는 핵심 화면.**

**C. 현장 도움 화면(Help Me Now + Plan B):** 촬영/질문 → 확인된 답변/미확인 사항 → 다음 행동 안내 → 실패할 때 대안과 외부 공식 경로. 직전 화면과 저장된 문맥을 사용자 동의 범위 내에서 이어받음.

### 5.3 전문 화면을 획일화하지 않기

| 전문 기능 | 주인공 UI | KoreaMate와 만나는 화면 요소 |

| K-Beauty AR | 얼굴/AR 미리보기·컬러·제품 세트 | '이 룩을 저장', '한국 방문 중 체험/구매 계획' |
| GG Korea Fan | 팀·경기·행사·굿즈 중심 시각 언어 | 경기 날짜 기준 하루 코스와 행사 충돌 안내 |

## 6. 기능 간 협력에 필요한 공통 계약

- `ExperienceCandidate`: ID, 도메인, 작품/이벤트/상품 관계, 사진·원본 링크, 국가/언어, 태그, 출처, 확인 시각, 확정/미확정 구분.
- `Place/Event`: 장소 ID·주소/좌표, 기간, 운영·예약 조건, 검증 시각과 출처, 미확인 상태.
- `TripContext`: 사용자가 선택한 언어, 일정, 이동 조건, 관심사, 예산, 저장 내용과 공유 동의 범위.
- `DomainResult`: 누가 어떤 전문 기능에서 어떤 근거로 무엇을 제안했는지.
- `ActionProposal`: 실행 전/후 일정 차이, 충돌, 예상 영향, 필요한 사용자 승인, 외부 서비스 링크, '진행 완료' 확인 여부.
- **기본 규칙:** 추천 근거 없는 기능 호출 금지; 마지막 확인 정보가 오래됐으면 현재 사실로 표현 금지; 사용자 승인 전 일정 임의 수정 금지; 임의 AI 추천/모의 응답을 실제 영업·예약 정보로 오인하게 하지 않음.

**AI 적용 위치:** 이미지/언어 이해 및 계획 설명은 LLM 도구 활용 후보. 행사·장소·자격·시간 검증은 구조화 API/규칙 우선. 여러 검증/추천/일정 작업을 조율하고 결과 충돌을 해소할 때 다중 에이전트의 추가 가치 검증. RAG는 한국 문화·문법·이용 안내 근거 검색, ML/DL은 개인화 추천 등 뚜렷한 태스크별 성능 비교. 페이지 수만큼 에이전트를 분리할 필요 없음.

## 7. 시연/사용자 검증 기준

**필수 3개 증명 과제**

1. **A: SNS → 운영 확인 → 방문 불가 → 대안 → 일정 반영**: KoreaMate의 원안 가치와 S01을 증명.
2. **B: Kravel 일정 → K-Season 행사 → 시간 충돌 해소 → 새 일정 적용**: A→B→A 결과 변경으로 융합 증명.
3. **C: K-Beauty 독립 체험 → 선택 제품/룩 저장 → 한국 방문 계획 연결**: 각 팀원 고유 경험이 약해지지 않는지 증명.

**추가 팀원 체험:** K-Class 학습자/튜터 모드, GG Fan/Pro 모드를 원래 목적 그대로 조작해 보는 별도 과제. 음식 B2B 분석은 별도 목적과 지표로 테스트.

**같은 조건 비교:** (1) 현행 v0.2 기능별 이동 방식 (2) 연결 기능이 없는 각 전문 서비스 (3) 새 융합 경험. 비교 항목은 과제 성공, 실제 절약 시간, 오류/오인식, 인지한 정보 신뢰도, 독립 체험 만족도, 추천의 설득력, 새로운 경험 발견량.

**검증 질문:** '둘 중 하나가 없어도 같은 결과가 나오는가?' 그렇다면 연결 수준이고 융합이라고 주장하기 어려움. '전문 기능 없이 KoreaMate가 같은 가치를 쉽게 재현하는가?' 그렇다면 전문 기능의 독립적 가치가 화면에서 전달되지 않은 것.

## 8. 의사결정 제안

- **원래 정체성 고정:** 문화 발견+현지 도움+실제 실행. AI Mate는 만능 메뉴가 아니라 컨텍스트를 이어주는 동반자.
- **첫 융합 증명:** S01과 S02를 하나의 행사 검증+여행 재계획 엔진으로 묶어 재사용.
- **매력적인 독립 체험:** S03 K-Beauty, S04 GG Fan, S05 K-Class 등은 독립 경험 완성도를 살리면서 연결 지점을 설계.
- **포괄 범위는 팀 합의:** 독립 후보·선택적 연결·깊은 통합을 하나의 확정으로 오인하지 않음. 팀원별 기능 대표 장면과 연결 계약을 논의.
- **다음 화면 설계 순서:** (1) 콘텐츠 이해 (2) Kravel-K-Season 결과 재계획 (3) 현장 Help Me Now/Plan B (4) Beauty AR 체험 및 연결 (5) 이 결과에서 메인을 역설계.
